# SuperCache API docs (static)

This directory is the static site published to **GitHub Pages**.

- Live on a node: `http://<admin-host>/docs` (served by `supercache-node`)
- Specs source of truth: [`api/openapi/`](../../api/openapi/)
- UI shell source: [`pkg/admin/docsui/`](../../pkg/admin/docsui/)

When editing OpenAPI or the UI, update the sources above and re-copy (or rely on
the docs workflow) so this tree stays in sync.
