# Hash type (`ModeHash`)

**Status:** approved  
**Branch:** `feat/mode-hash`

## Problem

SuperCache already has:

| Mode | Shape |
|------|--------|
| CacheOnly / LoadThrough | opaque `key → []byte` |
| Bloom | approx membership |
| Set | exact membership, no values |
| ZSet | member → `float64` score |
| Geo | member → lon/lat |
| List | ordered sequence |

There is no **named hash** (`name → { field → []byte }`) with per-field mutate. Callers today either:

- rewrite one KV blob on every field change (lost concurrent field updates; every write is a full `Put`),
- flatten to `name\x00field` keys (RF multiplies keys; `HLen` / `HGetAll` / `Delete(name)` become scans),
- abuse Set (no values), ZSet (scores only), or List (not field-keyed).

Hash is **not contract-redundant**. It is the first type with per-field last-write-wins values.

Hash is **implementation-overlapping** with ModeSet / ModeZSet / ModeGeo: same owner-serialize, live cache + lazy encode, `Delete(name)` tombstone, empty-until-delete.

## Non-goals

- `HINCRBY` / `HINCRBYFLOAT` (increments are not commutative under lost hints; v1 is last-write-wins per field)
- `HMGET` / `HMSET` / `HSETNX` as separate RPCs (`HSet` / `HGet` / `HGetAll` are enough)
- `HKEYS` / `HVALS` as separate RPCs (`HGetAll` is enough)
- `HSCAN`
- Per-field TTL / `HEXPIRE` (whole-hash `TTL` only)
- Redis wire protocol
- Changing RF, tombstones, **hint identity** (`hintID` stays `(ks, name)` except `FlagBloomAdd`), or existing Get/Put/Delete / Bloom / Set / ZSet / Geo / List contracts
- Persistence across process restart
- A hard per-hash size cap beyond existing store rules: cost uses `ApproxWireBytes()`; live `FlagHash` is LRU-protected so a **single** hash may overshoot `MaxBytes` (same as Set/Geo/List). Per-op caps remain `MaxKeyLen` / `MaxValueSize`.
- A new default demo keyspace in the implementation PR
- scbench YAML cells in v1

## Contract

### API (new; existing verbs unchanged)

On `pkg/engine.Engine`, `pkg/client.Client`, Cache proto, and **`cmd/sc`** (same PR as the type):

| Call | Meaning |
|------|---------|
| `HSet(ks, name, field, value)` | Upsert field. Creates hash if missing. |
| `HGet(ks, name, field) (value []byte, ok bool, err error)` | Missing hash or field → `ok=false`, nil error. |
| `HDel(ks, name, field)` | Remove field if present. No-op if missing / hash missing. Does **not** `Delete` the name. |
| `HExists(ks, name, field) (bool, error)` | Missing hash or field → `false`, nil error. |
| `HLen(ks, name) (int, error)` | Field count. Missing → `0`. |
| `HGetAll(ks, name) ([]HashField, error)` | All field/value pairs (defensive copies), **field-byte order**. Missing → empty. |
| `Delete(ks, name)` | Existing Delete: whole-hash tombstone. |

```go
type HashField struct {
	Field []byte
	Value []byte
}
```

- `name` is the hash identity; ring owner = `Owner(name)`. Validated with `validateKey` + `validateKeyLen` (per-keyspace `MaxKeyLen` applies to **name** only).
- `field` is `[]byte`. Empty field → `ErrInvalidArgument` on **all** field-taking verbs (`HSet`, `HGet`, `HDel`, `HExists`). `len(field) > e.maxKeyLen` → `ErrKeyTooLarge` on those same verbs. Field length uses the **engine** default (`e.maxKeyLen`, default `keyspace.DefaultMaxKeyLen` = 512), **not** per-keyspace `MaxKeyLen` (same as Set/Geo members).
- `value` is `[]byte`. Checked **only on `HSet`** via `validateValueSize` (`e.maxValueSize` or per-keyspace `Config.MaxValueSize`, default `keyspace.DefaultMaxValueSize` = 1 MiB). **Empty value is allowed.** Nil value is stored as empty. `HGet` of a stored empty value returns a **non-nil** `[]byte{}` copy with `ok=true`.
- `HGet` / `HGetAll` **copy** field and value bytes out of the live map (same as `ZRange` / `LIndex`). Mutating a returned `[]byte` must not change the store.
- Each **owner** mutate (`HSet` / `HDel` on the client-hit-owner path) refreshes whole-hash `ExpireAt` from keyspace `TTL` (`0` = none), same as `GeoAdd`. ApplyPut paths use inbound `expireAt`, or `e.expireAt(TTL)` when the wire value is `0`.
- Get/Put on `ModeHash` → `ErrInvalidArgument`.
- Hash verbs on non-`ModeHash` → `ErrInvalidArgument`.
- Cross-mode misuse (HSet on ModeSet, SetAdd on ModeHash, …) → `ErrInvalidArgument`.

**Not in v1:** HINCRBY*, HMGET/HMSET/HSETNX, HKEYS/HVALS RPCs, HSCAN, per-field expire, Redis wire.

### Keyspace

New mode `keyspace.ModeHash` (next iota after `ModeList`). `Mode.String()` must return `"Hash"` (else `/keyspaces` prints `Mode(7)`).

| Field | Role |
|-------|------|
| `MaxBytes` | Cost budget. Live `FlagHash` is LRU-protected; one hash may **overshoot** (same as Set/Geo/List) |
| `TTL` | Expires the **whole** hash; owner mutate slides `ExpireAt` |
| `NegativeTTL` | Ignored |
| `TombstoneTTL` | On `Delete(name)` |
| `ReplicationFactor` | Same as KV / ModeSet / ModeGeo |
| `MaxKeyLen` | Bounds `name` only |
| `MaxValueSize` | Bounds each field **value** on `HSet` |

No extra hash-size knob in v1.

### Replication (locked: item-level like Set / ZSet / Geo)

Field ops are **commutative**: `HSet A` then `HSet B` = `HSet B` then `HSet A`. Missing an earlier op of a *different* field leaves a valid but incomplete hash (same replica-staleness class as Set/ZSet/Geo). Last `HSet` of the **same** field winning under hint coalesce is correct.

**Do not change `hintID`.** Actual identity in `internal/peer/hints.go`:

```go
func hintID(ks, key string, ent store.Entry) string {
    if ent.IsBloomAdd() {
        return ks + "\x00" + key + "\x00" + string(ent.Value)
    }
    return ks + "\x00" + key
}
```

Every non-`FlagBloomAdd` hint coalesces per `(ks, name)`. A second mutate of the same name **replaces** the pending hint. That is already how shipped Set/ZSet/Geo behave (their designs claimed per-item IDs; implementation does not).

| Op | Client-hit-owner | ApplyPut (non-owner inbox + replica) | Replicas |
|----|------------------|--------------------------------------|----------|
| `HSet` | `hNextVersion` + store `HSet` + replicate item flag at that version | apply inbound `ent.Version` (often `1`); do **not** mint | `FlagHashSet` apply |
| `HDel` | `hNextVersion` if a live hash exists; missing name = no-op, no insert | apply inbound `ent.Version`; missing name = no-op | `FlagHashDel` apply |
| `Delete(name)` | tombstone | `ApplyDelete` | `ApplyDelete` |
| Handoff | full snapshot | `FlagHash` install if incoming version **>** local (equal = ignore; tombstone blocks if incoming ≤ tombstone). **Not union.** |

**Wire:** reuse **ApplyPut** with new flags (no new Peer RPC names):

| Flag | Value payload |
|------|----------------|
| `FlagHash` `1<<16` | full encoded hash (handoff / GetOrLoad snapshot) |
| `FlagHashSet` `1<<17` | `hashx.EncodeSet(field, value)` (exactly one record) |
| `FlagHashDel` `1<<18` | **raw field bytes** (same as `FlagGeoRem` / `FlagSetRemove`; not EncodeSet) |

Confirm unused today: last shipped bit is `FlagListRPush` `1<<15` in `pkg/store/entry.go`.

**ApplyPut version (locked: match shipped Set/Geo, not List):**

1. Non-owner mutate: `ApplyPut` `{Flags: FlagHashSet\|FlagHashDel, Value: EncodeSet(...)|raw field, Version: 1}`.
2. `applyHashSet` / `applyHashDel`: decode payload → `store.HSet` / `HDel(..., ent.Version, expireAt)` (**incoming** version; `expireAt == 0` → `e.expireAt(TTL)`).
3. If this node is owner, `replicate` the **same inbound `ent`** (do not rewrite version). `ApplyPutWithRingGen` already `observeVersion`s.
4. **Only** the client-hit-owner Engine method uses `hNextVersion` (`PeekVersion`) + store mutate + `replicate` at that version.

Do **not** call `hNextVersion` inside `applyHashSet` / `applyHashDel`. List’s `applyListLPush` is the wrong template.

**Owner-inbox vs replica-apply (locked):**

- Replicas **do** apply `FlagHashSet` / `FlagHashDel` (like `FlagSetAdd` / `FlagGeoAdd`).
- Owner `ApplyPut` of those flags applies the op and **re-fans-out the same inbound `ent`**.
- Handoff / `GetOrLoad` install uses `FlagHash` snapshot only (version gate; not union).

**Reads (locked: same as `GeoPos` / `SetContains`):**

- If `HasHash` local → **store only**. A missing field is `ok=false` / `false`. **Do not** owner-forward a local miss.
- Else if this node is owner → missing hash → empty / `ok=false`.
- Else (non-replica, no local hash) → `Transport.GetOrLoad` owner snapshot; replica-in-RF may `HInstall` then answer; non-replica decodes without storing.
- Owner always has the complete LWW hash after its own mutates.

**Hint-loss caveat (normative):** if a replica is down for `HSet(name, A, …)` then `HSet(name, B, …)`, the pending hint is **only B**. After replay the replica has a live hash that may lack A. Because `HasHash` is true, `HGet(A)` / `HExists(A)` on that replica are **local misses** until a later `FlagHash` snapshot (`GetOrLoad` install on a later read that did not short-circuit, or join handoff). They do **not** owner-forward. A **non-replica** (no local hash) `GetOrLoad`s the owner and sees A. The hint-after-down test **must not** require both fields on the replica’s local copy, and **must not** `t.Fatal` if the replica’s local `HGet(x)` is false while `HasLocal`.

No new peer RPC (no pop/result payload).

Owner serializes client writes; **last write wins** for a field’s value.

### Empty after last `HDel`

Keep an empty `FlagHash` entry (`HLen` 0) until `Delete(name)` (same as Set/ZSet/Geo/List). `HDel` of a **missing name** is a no-op and **does not create** an empty hash (match `store.SetRemove`).

### What existing clients can assume

- CacheOnly / LoadThrough / Bloom / Set / ZSet / Geo / List unchanged if they never open `ModeHash`.
- No new default node keyspace (`-demo-keyspace` stays `demo` / `tags` / `board`).
- Rolling: do **not** register a `ModeHash` keyspace until every node has the Hash `ApplyPut` branches. An old node would fall through `ApplyPutWithRingGen` to `AcceptIfNewer` and treat `Mode=7` as KV.

## Approach

### In-memory (`pkg/hashx`)

Package **`pkg/hashx`** (avoid clash with hash ring, `crypto`, and the stdlib `hash` import). Same rationale as `pkg/listx`.

```go
package hashx

type Field struct {
	Field []byte
	Value []byte
}

type Hash struct {
	// field bytes as Go string key (same as pkg/set); string(field) copies
	m map[string][]byte
}

func New() *Hash
func (h *Hash) Set(field, value []byte)     // copy value in; nil value → empty
func (h *Hash) Del(field []byte)
func (h *Hash) Get(field []byte) ([]byte, bool) // copy value out
func (h *Hash) Exists(field []byte) bool
func (h *Hash) Len() int
func (h *Hash) All() []Field                // copies of field and value, bytes.Compare order
func (h *Hash) Encode() []byte
func (h *Hash) ApproxWireBytes() int64
func Decode(b []byte) (*Hash, error)
func EncodeSet(field, value []byte) []byte  // exactly one record; no sort
func DecodeSet(b []byte) (field, value []byte, err error)
```

**Encode (canonical):** fields sorted by raw field bytes (`bytes.Compare`, equivalent to `sort.Strings` on the map keys):

```text
for each (field, value) in field-byte order:
  uvarint(len(field)) + field + uvarint(len(value)) + value
```

Empty hash → `[]byte{}`.

**Decode edges (locked):**

- Walk to exhaustion. Bad/truncated uvarint or short payload → error.
- Duplicate field keys on the wire → **last-wins** (later record overwrites).
- `EncodeSet` writes exactly one record (no sort).
- `DecodeSet` errors on 0 records **or leftover bytes after one pair** (not “2+ decoded pairs” only).
- `Get` of a stored empty value returns a **non-nil** empty copy + `ok=true`.
- `Set` copies the value in; `Get` / `All` copy field and value out.

`ApproxWireBytes` = sum of uvarint sizes + field + value lengths (no alloc).

### Store (`pkg/store`)

New flags and helpers on `Entry` (`IsHash` / `IsHashSet` / `IsHashDel`).

```go
// store.Store — lock these signatures (mirror Geo / SetRemove)
HSet(key string, field, value []byte, version uint64, expireAt int64) bool // create if missing
HDel(key string, field []byte, version uint64, expireAt int64) bool        // missing name: true, no insert
HGet(key string, field []byte) (value []byte, ok bool)                    // copy
HExists(key string, field []byte) bool
HLen(key string) int
HasHash(key string) bool
HGetAll(key string) []HashField                                           // copies, field-byte order
HInstall(key string, blob []byte, version uint64, expireAt int64) bool    // incoming > local; equal ignore; tombstone <= blocks
```

`store.HashField` is `{Field, Value []byte}` (same shape as `engine.HashField` / `hashx.Field`).

`HSet` / `HDel` return `false` only when blocked (higher-or-equal tombstone, or live non-hash entry). Missing name on `HDel`: `true`, no insert (copy `SetRemove`). `HSet` creates an empty hash then sets the field.

Live `hCache *hashx.Hash` + `hDirty` on `lruItem`, mirroring `gCache` / `lCache`:

- `HSet` / `HDel` mutate cache; approximate cost via `ApproxWireBytes()`; encode on Peek/Get (`flushHashValueLocked`).
- `HGet` / `HExists` / `HLen` / `HGetAll` / `HasHash` use cache (0-alloc hot path for Exists/Len when warm).
- `HInstall` versioned snapshot replace (same gate as `GeoInstall`: incoming `>` local; equal ignore; tombstone blocks if `<=`). **Not union.**
- Protect live `FlagHash` from LRU in `lruVictim` alongside Set/ZSet/Geo/List/Bloom/tombstone. A single protected hash may grow until `evictLocked` cannot pick a victim and the store **overshoots** `MaxBytes`.
- `Peek` / `Get` call `flushHashValueLocked` next to `flushListValueLocked`. The helper **must be 0-alloc** when `!hDirty || hCache == nil || !IsHash` (copy `flushListValueLocked`). KV Get-hit must not allocate inside this flush.
- Plain `Set` / `AcceptIfNewer` clear `hCache`/`hDirty` like the other caches.

### Engine (`pkg/engine/hash.go`)

Mirror `pkg/engine/geo.go` / `set.go` (not `list.go` apply):

1. Validate mode `ModeHash`, `name` via `validateKey` + `validateKeyLen`.
2. Field-taking verbs (`HSet`/`HGet`/`HDel`/`HExists`): empty field → `ErrInvalidArgument`; `len(field) > e.maxKeyLen` → `ErrKeyTooLarge`.
3. `HSet` only: `validateValueSize(value)`.
4. **Client-hit-owner:** `hNextVersion` (`PeekVersion` so dirty encode is not flushed), store mutate, `replicate` `FlagHashSet` (`EncodeSet`) / `FlagHashDel` (raw field) at that version + `expireAt`.
5. **Non-owner mutate:** `hMutViaOwner` = `Transport.ApplyPut` with `{Flags, Value, Version: 1}` — same as `gMutViaOwner`. Do **not** mint a version on the owner inside apply.
6. **Reads:** if `HasHash` local → store (no forward on miss). Else `hFetchOwner` via `GetOrLoad`; if `holdsReplica`, `HInstall` then answer.
7. Get/Put reject `ModeHash` (`use HGet` / `use HSet`).
8. `GetOrLoadLocal`: Peek + `IsHash` (same as Geo/List).
9. `LocalEntries` already walks `RangeAll`; Peek flush makes the snapshot blob current.

**`ApplyPutWithRingGen` (after `IsList`, before `IsNegative`):**

```go
if ent.IsHashSet() {
    ok := e.applyHashSet(ks, key, ent.Value, ent.Version, ent.ExpireAt)
    if ok {
        if c := e.clusterSnapshot(); c != nil && c.Ring != nil {
            if owner, yes := c.Ring.Owner(key); yes && owner.ID == c.SelfID {
                e.replicate(keyspaceName, key, ent, false) // same inbound ent
            }
        }
    }
    return ok, nil
}
if ent.IsHashDel() {
    ok := e.applyHashDel(ks, key, ent.Value, ent.Version, ent.ExpireAt)
    if ok {
        if c := e.clusterSnapshot(); c != nil && c.Ring != nil {
            if owner, yes := c.Ring.Owner(key); yes && owner.ID == c.SelfID {
                e.replicate(keyspaceName, key, ent, false)
            }
        }
    }
    return ok, nil
}
if ent.IsHash() {
    return e.applyHashInstall(ks, key, ent.Value, ent.Version, ent.ExpireAt), nil
}
```

```go
func (e *Engine) applyHashSet(ks *ksRuntime, name string, value []byte, version uint64, expireAt int64) bool {
    field, val, err := hashx.DecodeSet(value)
    if err != nil {
        return false
    }
    if expireAt == 0 {
        expireAt = e.expireAt(ks.cfg.TTL)
    }
    return ks.store.HSet(name, field, val, version, expireAt)
}

func (e *Engine) applyHashDel(ks *ksRuntime, name string, field []byte, version uint64, expireAt int64) bool {
    if expireAt == 0 {
        expireAt = e.expireAt(ks.cfg.TTL)
    }
    return ks.store.HDel(name, field, version, expireAt) // payload is raw field bytes
}

func (e *Engine) applyHashInstall(ks *ksRuntime, name string, blob []byte, version uint64, expireAt int64) bool {
    if expireAt == 0 {
        expireAt = e.expireAt(ks.cfg.TTL)
    }
    return ks.store.HInstall(name, blob, version, expireAt)
}
```

```mermaid
sequenceDiagram
  participant C as Client
  participant N as Non-owner
  participant O as Owner
  participant R as Replica
  C->>N: HSet(name, field, value)
  N->>O: ApplyPut FlagHashSet EncodeSet Version=1
  O->>O: applyHashSet(ent.Version) no mint
  O->>R: replicate same inbound ent
  O-->>N: ACK
  N-->>C: OK
  Note over R: apply field op (commutative)
  C->>R: HGet(name, otherField)
  Note over R: HasHash → local only; miss does not forward
  C->>N: HGet(name, field)
  alt N holds replica copy
    N-->>C: local HGet (no owner-forward on miss)
  else non-replica
    N->>O: GetOrLoad(name)
    O-->>N: FlagHash snapshot
    N-->>C: decode field
  end
```

### Client / proto / sc

**Hint after peer down (locked):** Set/Geo shape, **not** List.

1. Owner `HSet(x)` while B is down, then `HSet(y)` after B is up.
2. Owner `HGet(x)` still `ok=true`.
3. Do **not** `t.Fatal` if `engB`’s store lacks `x`, or if `HGet(x)` is false while `HasLocal` (coalesce dropped A; replica local-only).

## Bench risk

**Hot path?** No — KV Get must not call hash **logic**. `Get`/`Peek` will invoke `flushHashValueLocked` on every key (same as the other flush helpers). That helper must return immediately with **0 allocs** when `!hDirty || hCache == nil || !IsHash`. Isolate ModeHash in `Get`/`Put`/`ApplyPut`/`lruVictim` so Get-hit allocs stay flat.

Local bench before commit: `BenchmarkEngineGetHit` / `BenchmarkStoreGetHit` allocs/op must not rise.

Smoke: noise only if Get-hit / StoreGetHit **allocs/op** stay flat. Merge bar ±10% shared cells.

New micros: first-merge baseline only; later PRs treat Hash HLen allocs as a “must stay 0 when warm” check.

## Key Decisions

| Decision | Lock | Rationale |
|----------|------|-----------|
| Name | `Hash` / `ModeHash` / `H*` | Same naming as Geo; Redis-familiar verbs |
| API surface | HSet, HGet, HDel, HExists, HLen, HGetAll, Delete(name) | Smallest complete field map; HGetAll covers keys/vals |
| Value size | `MaxValueSize` (default 1 MiB), **HSet only** | Value type, not member-only; reuse `validateValueSize` |
| Field size | engine `maxKeyLen` (default 512); empty rejected on **all** field verbs | Same as Set/Geo members; per-ks `MaxKeyLen` is name-only |
| Empty value | allowed; HGet → non-nil empty + `ok=true` | Distinct from missing |
| Fan-out | **Item-level** `FlagHashSet` / `FlagHashDel` | Field ops commute; O(1) network per field; match shipped Set/ZSet/Geo |
| ApplyPut version | inbound `ent.Version`; owner re-replicates **same `ent`**; `hNextVersion` only on client-hit-owner | Match `gMutViaOwner` / `applyGeoAdd`, not List |
| hintID | **unchanged** `(ks, name)` | Out of scope |
| Replica reads | `HasHash` → local only; no owner-forward on field miss | Match `GeoPos` / `SetContains` |
| Replica apply | replicas apply item flags | Same as FlagSetAdd / FlagGeoAdd |
| Handoff | `FlagHash` snapshot, not union | Removes on owner must not be undone by a lagging replica |
| FlagHashDel payload | raw field bytes | Same as FlagGeoRem / FlagSetRemove |
| HLen proto | `int64 len = 1` | Match List, not Set `card` |
| Package | `pkg/hashx` | Avoid `hash` / ring / crypto clash (`listx` precedent) |
| Empty-until-delete | keep empty entry after last HDel | Same as Set/ZSet/Geo/List |
| MaxBytes | live hash LRU-protected; may overshoot | Same as Set/Geo/List |
| sc value | `Join(args[2:], " ")`; hgetall `field<TAB>value`; no `-file` | Values may contain spaces; no binary-file path in v1 |
| No HINCRBY | excluded | Increments are not commutative under lost hints |
| Persistence | none | Same as every other type |
| Product docs | same implementation PR | WORKFLOW §5b |
| CLUSTER_FLOWS | extend existing E10/E11 | Do not add new mermaid nodes |
| Examples / demo KS | follow-up PR | No new default keyspace in the product PR |
| Peer RPCs | none new | ApplyPut flags + GetOrLoad suffice (no pop payload) |

## Security & privacy

No new auth surface. Hash names/fields/values are opaque bytes on the existing Cache gRPC (TLS) and Peer ApplyPut (mTLS). Do not log field values. Limits (`MaxKeyLen` / `MaxValueSize`; `MaxBytes` may overshoot one live hash) are the DoS bound. Same tenant isolation as other modes: keyspace config is local and must match across nodes.

## Observability

Reuse existing fan-out / hint / `staleSkip` / store hit-miss counters. No new required metrics in v1. Optional later: field-count histogram. Wrong-mode and oversize already map through `grpcmap`.

## Rollout / rollback

- Opt-in: nothing happens until an operator registers a `ModeHash` keyspace on **every** node.
- Deploy the Hash build cluster-wide first; then `UpdateKeySpace`.
- Rollback: stop writing Hash verbs; `Delete(name)` or drop the keyspace. No on-disk format.
- No feature flag (mode is the flag).

## Open points (resolved)

1. **Naming:** **ModeHash** / **H\*** (not ModeMap / ModeHMap).
2. **Fan-out:** **item-level** like Set/ZSet/Geo; hint-coalesce caveat documented; replica with `HasHash` is local-only; test must not require both fields locally.
3. **ApplyPut version:** inbound `ent.Version`; owner re-replicates the same `ent`; `hNextVersion` only on client-hit-owner (Set/Geo, not List).
4. **Value limit:** **MaxValueSize** on HSet only.
5. **Empty after last HDel:** keep empty entry until `Delete(name)`.
6. **Empty value:** allowed; HGet returns non-nil empty + `ok=true`.
7. **Empty field:** invalid on **all** field-taking verbs.
8. **Package:** **`pkg/hashx`**.
9. **HINCRBY:** **not in v1**.
10. **Peer RPC:** **none new**.
11. **HLen proto field:** **`len`** (List), not `card`.
12. **sc:** Join `args[2:]`; hgetall TAB; no `-file`/stdin.
13. **Demo keyspace:** **not in this PR**.
14. **CLUSTER_FLOWS:** extend existing E10/E11.

## Rejected alternatives

| Idea | Why not |
|------|---------|
| One KV blob rewritten by the app | Full rewrite; concurrent field updates clobber each other |
| Flattened keys `name\\0field` | Multiplies RF keys; no cheap HLen/HGetAll/Delete(name) |
| Overload ModeSet / ModeZSet / ModeList | No values / scores only / not field-keyed |
| Full snapshot fan-out every HSet (`FlagHash` only) | Correct under current hintID (List’s reason) but O(n) network per field; Hash ops commute so item-level is safe |
| Change hintID to per-field in this PR | Touches global hint path; out of scope |
| List-style `hNextVersion` inside apply | Forks Set/Geo version sequences; wrong template |
| Owner-forward HGet when replica HasHash | Would change shipped Set/Geo read contract; extra hop on every miss |
| HINCRBY in v1 | Lost hints make increments non-commutative |
| CRDT map / per-field versions | Heavier; owner serialization makes LWW enough |
| Redis wire protocol | Different product surface |
