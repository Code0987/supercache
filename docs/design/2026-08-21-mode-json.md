# JSON type (`ModeJSON`)

**Status:** approved  
**Branch:** `feat/mode-json`  
**Date:** 2026-08-21

## Problem

SuperCache has no **named nested document** with path mutate. Callers who want JSON today abuse a wrong type:

| Mode | Shape | Why it is not JSON |
|------|--------|---------------------|
| CacheOnly / LoadThrough | `key → []byte` | Whole-doc rewrite. Two writers touching different paths LWW the **entire** blob (`pkg/engine/engine.go` `Put`). |
| `ModeHash` | flat `field → []byte` | No nesting, no arrays, no typed numbers/bools/null, no `$.a.b[0]`. Hash values are opaque bytes, not JSON. See [2026-08-20-mode-hash.md](./2026-08-20-mode-hash.md). |
| `ModeList` | sequence of `[]byte` | Not a document. |
| `ModeCounter` | one `int64` | Not a document. |
| Set / ZSet / Geo / Bloom | membership / score / point / filter | Not a document. |

JSON is the first **nested, typed document** with path get/set/delete. It is **not** Hash-with-JSON-values.

This is new product behavior on the data path. Full path in [WORKFLOW.md](../WORKFLOW.md): design → review → (after approval) tests → code → bench → PR. **No tests or implementation until this draft is approved** (`looks good` / `do it` / `implement`).

## Non-goals

- RedisJSON full path language (`..`, `*`, filters, unions)
- `JSON.NUMINCRBY`, `JSON.ARRAPPEND` / `ARRINSERT` / `ARRPOP`, `JSON.STRAPPEND`, `JSON.MERGE`, `JSON.MGET`
- JSON Schema, BSON, MsgPack as the public type
- `JsonType` in v1 (object/array/string/number/bool/null) — cheap later; skip so the first PR stays small
- Per-path TTL
- Negative array indexes (List has them; JSON v1 does not)
- Auto-creating arrays (`$.a[0]` on missing `a` is invalid)
- Changing RF, tombstones, **hint identity** (`hintID` stays `(ks, name)` except `FlagBloomAdd` in `internal/peer/hints.go`), or existing Get/Put/Delete / Bloom / Set / ZSet / Geo / List / Hash / Counter contracts
- Persistence across process restart
- A new default `-demo-keyspace` JSON keyspace (Hash already added `profile`)
- scbench YAML cells
- A new Peer RPC (`JsonSet` / `JsonDel` are ACK-only)

`NUMINCRBY` / `ARRAPPEND` are **follow-up**. They are not commutative under lost item-hints (Hash already excluded `HINCRBY`). Whole-document snapshot fan-out **would** make them correct; they are still out of v1 to keep the first PR small.

JSON was never listed as a PLAN non-goal. Do not invent a §1 fight.

## Why not item-level fan-out (locked)

Path updates of **different** paths commute like Hash fields, but `hintID` is still `(ks, name)`:

```go
// internal/peer/hints.go
func hintID(ks, key string, ent store.Entry) string {
    if ent.IsBloomAdd() {
        return ks + "\x00" + key + "\x00" + string(ent.Value)
    }
    return ks + "\x00" + key
}
```

A second mutate of the same name **replaces** the pending hint. Item-level `FlagJSONSet(path, value)` on the replica wire would drop an earlier *other* path (same Hash caveat). Array-shaped future ops (`ARRAPPEND`) are List-class.

**v1 wire:** every owner mutate fans out a **full encoded document** (`FlagJSON` `1<<20`) at the post-op version. Hint coalesce keeps the newest snapshot — that is correct. O(n) network per set; `MaxValueSize` (default 1 MiB, `keyspace.DefaultMaxValueSize`) caps n.

**No `FlagJSONSet` / `FlagJSONDel` on the replica wire.** Those flags are **owner-inbox only** (List `FlagListLPush` / `FlagListRPush` in `pkg/engine/list.go` / `ApplyPutWithRingGen`).

Rejected for v1: per-path replica apply; hintID change; op-log + snapshot-on-gap.

## Contract

### API (new; existing verbs unchanged)

On `pkg/engine.Engine`, `pkg/client.Client`, Cache proto, and **`cmd/sc`** (same PR as the type):

| Call | Meaning |
|------|---------|
| `JsonSet(ks, name, path, value []byte)` | Upsert JSON value at path. Creates the document if missing. |
| `JsonGet(ks, name, path) (json []byte, ok bool, err error)` | Missing doc or missing path → `ok=false`, nil error. Path `$` or `""` = whole document. |
| `JsonDel(ks, name, path)` | Remove node at path. `$` / `""` clears to `{}` (document stays live). Missing path is a no-op. |
| `Delete(ks, name)` | Existing Delete: whole-document tombstone. |

```go
JsonSet(ctx context.Context, keyspace, name, path string, value []byte) error
JsonGet(ctx context.Context, keyspace, name, path string) (json []byte, ok bool, err error)
JsonDel(ctx context.Context, keyspace, name, path string) error
```

- `name` is the document identity; ring owner = `Owner(name)`. Validated with `validateKey` + `validateKeyLen` (per-keyspace `MaxKeyLen` applies to **name** only).
- `path` is UTF-8 text (proto `string`). Empty path ≡ `$`. `len(path) > e.maxKeyLen` (default `keyspace.DefaultMaxKeyLen` = 512) → `ErrKeyTooLarge` on **all** Json* verbs. Per-keyspace `MaxKeyLen` does **not** cap path (same as Hash fields).
- `value` is raw JSON bytes. Checked on `JsonSet` only:
  1. Invalid JSON (including empty / nil / trailing junk) → `ErrInvalidArgument`.
  2. `len(value) > MaxValueSize` → `ErrValueTooLarge` (initiating node, before apply/forward).
  3. After a successful path apply, if **encoded document** `> MaxValueSize` → `ErrValueTooLarge`, **do not mutate**.
- `JsonGet` **copies** JSON out (marshal of the selected node, or a copy of the stored blob at `$` when not dirty). Mutating the returned `[]byte` must not change the store.
- **Missing document ≠ JSON `null`.** A live `null` document (`JsonSet($, null)`) is present: `HasJSON == true`, `JsonGet($)` → `[]byte("null")`, `ok=true`. A missing name is `HasJSON == false`, `JsonGet` → `ok=false`. JSON `null` at a **child** path is also present (`ok=true`); a missing path is `ok=false`.
- Each **owner** mutate that actually changes the stored tree (`JsonSet` success, or `JsonDel` with `mutated=true`) assigns a **new stored version under the store mutex** (see [Version assignment](#version-assignment-locked)) and refreshes whole-doc `ExpireAt` from keyspace `TTL` (`0` = none) — scheme B / Hash / List / Counter. `JsonDel` of a missing name or missing path does **not** slide TTL or mint a version. ApplyPut paths use inbound `expireAt`, or `e.expireAt(TTL)` when the wire value is `0`. The inbound ApplyPut `Version: 1` on inbox flags is **not** the stored snapshot version.
- Get/Put on `ModeJSON` → `ErrInvalidArgument` (`use JsonGet` / `use JsonSet`).
- Json* on non-`ModeJSON` → `ErrInvalidArgument`.
- Cross-mode misuse (JsonSet on ModeHash, HSet on ModeJSON, …) → `ErrInvalidArgument`.

**Not in v1:** RedisJSON extras listed under Non-goals; `JsonType`.

### Path language (locked — tiny subset, not JSONPath)

Do **not** take full JSONPath. Grammar (`path` is the whole string; **no unquoted whitespace** — spaces are legal only inside `["…"]`):

```text
path     = "$" segment*
segment  = "." ident
         | "[" bracket "]"
bracket  = dq-string | index          // lexer decides; not “try index first”
ident    = [A-Za-z_][A-Za-z0-9_]*
index    = "0" | [1-9][0-9]*          // n >= 0; no '+'; no leading zeros except 0
dq-string = JSON string (encoding/json)
```

**Lexer after `[` (locked — one rule, no fork):**

1. If the next byte is `"`: parse the quoted key **only** with **`encoding/json`** (`json.Decoder` on the `"…"` token, or `json.Unmarshal` into a `string`). That is the object key. **Do not** use `strconv.Unquote` (Go string syntax: `\/` is an unknown Go escape, so `$["a\/b"]` would become `ErrPath` instead of key `a/b`). Do **not** hand-roll escapes (`\/`, `\uXXXX`, surrogates, `$["\u0022"]`).
2. Else: parse `index` (`0` or `[1-9][0-9]*`). Reject `+`, `-`, leading zeros (`01`), empty `[]`, and any value that does not fit `int` (`strconv.ParseUint` overflow / `n > math.MaxInt`). Overflow → `ErrPath`, not wrap.

| Form | Meaning |
|------|---------|
| `$` or `""` | Root |
| `.ident` | Object key (ASCII identifier) |
| `["utf8"]` | Object key (any JSON string, including spaces / dots / unicode) |
| `[n]` | Array index, `n >= 0` |

**Invalid path → `ErrInvalidArgument`** (all Json* verbs). Examples: `foo`, `$.`, `$..a`, `$.1a`, `$.a.b[`, `$[-1]`, `$[01]`, `$[+1]`, `$.a[ 0 ]` (unquoted space), `$['x']` (single quotes), `$["unterminated]`, `$[18446744073709551616]` (overflow).

**Not in v1:** recursive descent `..`, wildcards `*`, filters `?(…)`, unions, slices `[1:3]`, negative indexes.

`$["0"]` is an object key; `$[0]` is an array index. They are not interchangeable. `$[""]` is the empty object key. `$["a b"]` is a key containing a space. `$["\u0041"]` is key `A`. `$["a\/b"]` is key `a/b` (`\/` is a JSON escape; `encoding/json` accepts it).

### Path apply rules (locked)

**Missing document vs live JSON `null` (locked)**

| State | Go tree | `HasJSON` | Non-root `Set` | Non-root `Del` | Root `Set` | Root `Del` |
|-------|---------|-----------|----------------|----------------|------------|------------|
| Missing name | (no entry) | **false** | `JSet` starts from `map[string]any{}` then `Set` | no-op, no insert | install value | no-op, no insert |
| Live `null` | `jCache == nil` after `Decode("null")` | **true** | `ErrType` | no-op (`mutated=false`) | replace | `{}` (`mutated=true`) |

- `jsonx.Set` / `Del` treat Go `nil` as JSON **null**, never as “missing document”. Missing exists only in the store (`JSet` / `JDel`).
- `Set(nil /*JSON null*/, index-first path)` → `ErrType` (never allocate `[]any`).
- `Set(nil, object-key path)` → `ErrType` (null is a scalar parent).
- `Set(nil, root, val)` → `val` (root replace).
- Missing name + `JsonSet($[0], …)` → `JSet` starts from `{}`, then index-on-object → `ErrType` → **`ErrInvalidArgument`, no insert**.
- Missing name + `JsonSet($, null)` → live `null` document (`HasJSON` true).

**Create / parents**

- First `JsonSet` with path `$` installs that JSON (object, array, or scalar — including `null`).
- First `JsonSet` with a non-`$` path on a **missing** name starts from `{}` then applies the path (root becomes an object). Index-first paths therefore fail (`ErrType`) instead of creating an array.
- Missing **intermediate objects** are created: `JsonSet($.a.b, 1)` on `{}` → `{"a":{"b":1}}`.
- **Do not** auto-create arrays: `JsonSet($.a[0], 1)` on `{}` or missing `a` → `ErrInvalidArgument`.
- If a parent exists and is the **wrong type** for the next segment (object key on an array/scalar/null; index on an object/scalar/null) → `ErrInvalidArgument`.
- Setting `$.a` when `a` exists as a non-object **and the path continues** → `ErrInvalidArgument`. Replacing `$.a` itself (path ends at `a`) **overwrites** whatever was there.

**Arrays**

- `JsonGet` of `[n]` with `n >= len` → `ok=false` (missing path).
- `JsonSet` of `[n]`: parent must already be an array.
  - `n < len` → replace that element.
  - `n == len` → **append one** (grow by exactly one).
  - `n > len` → `ErrInvalidArgument` (no null-padding).
- `JsonDel` of `[n]`: `n >= len` or parent not an array → no-op. Otherwise **remove and shift** (array shrinks; not set-to-null).

**Root**

- `JsonSet($, value)` replaces the entire document.
- `JsonDel($)` (or `""`) replaces the document with live `{}`.

### Empty-until-delete (locked)

Prefer empty-until-delete (same spirit as Hash / List / Counter):

| Op | Result |
|----|--------|
| `JsonDel` of `$` | Document is `{}`, **still live** (`HasJSON` / `HasLocal` true). **`mutated=true` even if it was already `{}`.** |
| `JsonDel` of the last object key / last array element | Parent remains (`{}` or `[]`); document stays live; `mutated=true` |
| `JsonDel` of a missing path | No-op; `mutated=false`; **no version / TTL / snapshot** |
| `JsonDel` of a **missing name** | No-op; `mutated=false`; **does not create** `{}`; no version / TTL / snapshot |
| `JsonDel` of a non-root path on live `null` | No-op; `mutated=false` (type-mismatch parent) |
| `Delete(name)` | Tombstone; `JsonGet` → `ok=false` |

`JsonGet` of a live `{}` at `$` is `[]byte("{}")`, `ok=true`. Missing name is `ok=false`.

### Keyspace

New mode `keyspace.ModeJSON` (next iota after `ModeCounter`). `Mode.String()` must return `"JSON"` (else `/keyspaces` prints `Mode(9)`).

| Field | Role |
|-------|------|
| `MaxBytes` | Cost budget. Live `FlagJSON` is LRU-protected; one document may **overshoot** (same as Set/Geo/List/Hash) |
| `TTL` | Expires the **whole** document; owner mutate **slides** `ExpireAt` (scheme B) |
| `NegativeTTL` | Ignored |
| `TombstoneTTL` | On `Delete(name)` |
| `ReplicationFactor` | Same as KV / ModeList |
| `MaxKeyLen` | Bounds `name` |
| `MaxValueSize` | Bounds the **encoded document** after `JsonSet` **and** the incoming value bytes |

No extra JSON-size knob.

### Replication (locked: snapshot like List / Counter)

| Hop | Payload |
|-----|---------|
| Client → any node → **owner** | `ApplyPut` `FlagJSONSet` / `FlagJSONDel` (path + value) if this node is not owner |
| Owner → **replicas** | `FlagJSON` full snapshot after the op (encoded document + version + expire) |
| Handoff / `GetOrLoad` | `FlagJSON` install if incoming version **>** local (equal = ignore; tombstone blocks if incoming ≤ tombstone). **Not merge/union.** |

`JsonSet` / `JsonDel` are ACK-only — **no new Peer RPC**. Inbox flags + snapshot fan-out (List **push** pattern, not List pop / CounterIncr).

**Version assignment (locked — one rule for `JSet` and `JDel`):**

Both mutates assign the stored snapshot version **inside the store mutex**. There is **no** second version space (`jNextVersion` / `max(local, incoming)+1` is **not** used).

```text
if missing / expired (no live entry):     stored = 1          // JSet create only
if live FlagJSON or replacing tombstone:  stored = local.Version + 1
incoming `version` argument:              tombstone-gate floor only
                                          (reject if live tombstone && incoming <= tombstone.Version)
```

- Do **not** write the engine’s pre-lock `PeekVersion+1` / `jNextVersion` as `Entry.Version`.
- Engine fans out **`PeekVersion` after the store write** (then `observeVersion` that same value). Never fan out the candidate passed in.
- `applyJSONSet` and owner `JsonSet` use the **same** post-write Peek as `applyJSONDel` / owner `JsonDel`.
- Concurrent owner `JsonSet` overlapping `JsonDel` (or two dels, or two sets) serialize on the store mutex → distinct versions → `JInstall` (`incoming > local`, equal = ignore — `HInstall` at `pkg/store/memory.go:1542-1545`) cannot drop the later snapshot.
- `JsonDel` never creates; create/`stored=1` is `JSet` only.

**Owner-inbox vs replica-apply (locked — copy List, not Hash):**

- Non-owner: `Transport.ApplyPut` `{Flags: FlagJSONSet\|FlagJSONDel, Value: inbox payload, Version: 1}`.
- Owner `ApplyPut` of those flags: **apply the op** (`JSet` / `JDel` first). Pass `PeekVersion+1` (0→1 if missing) **only** as the tombstone-gate floor. Do **not** use inbound `Version: 1` as the stored version. If the store reports a mutate (`JSet` applied, or `JDel` `mutated`), `ver, _ := PeekVersion(name)` then `ks.observeVersion(name, ver)` + `jReplicateSnapshot(..., ver, ...)`.
- Replica `ApplyPut` of `FlagJSONSet` / `FlagJSONDel`: **ignore** (`return false, nil`) if this node is not owner — same guard as `IsListLPush` in `pkg/engine/engine.go` `ApplyPutWithRingGen`. Do not send inbox flags to replicas.
- `FlagJSON` → `JInstall` version gate only.

**Owner-local `JsonSet` / `JsonDel`:** same as inbox apply — store first, fan out `PeekVersion` after write. Do **not** call `jNextVersion` for either verb.

- `JsonSet`: `JSet` with gate `PeekVersion+1`. `tooLarge` → `ErrValueTooLarge`. `!applied` → `ErrInvalidArgument`. If applied → Peek + observe + snapshot.
- `JsonDel`: `JDel` first (no `HasJSON` prefetch). If `!ok` → `ErrInvalidArgument`. If `!mutated` → return nil (missing name / missing path / type-mismatch parent), no fan-out. If `mutated` → Peek + observe + snapshot. `JsonDel($)` of already-`{}` is `mutated=true`. `JsonDel` never creates a document.

**Non-owner `applied=false`:** initiating node already rejected bad path / bad JSON / oversize **value**. Owner reject (type clash, encoded-doc overflow, tombstone, non-JSON entry) surfaces as `ErrInvalidArgument` (`json set rejected` / `json del rejected`). Encoded-doc `ErrValueTooLarge` is guaranteed on the **owner-hit / single-node** path (tests lock that). Clustered merge-overflow cannot carry `ErrValueTooLarge` over ACK-only `ApplyPut` without a new RPC — do not add one.

**Reads (locked: same as `hFetchOwner` / `lFetchOwner` / `cFetchOwner`):**

- If `HasJSON` local → extract path from the **local** document. Replica snapshot may **lag**. A missing path is `ok=false`. **Do not** owner-forward a local hit.
- Else if this node is owner → missing document → `ok=false`.
- Else → `jFetchOwner` (copy of `hFetchOwner`):
  - `GetOrLoad` RPC error / owner down / `!Found` / `!IsJSON` / `Decode` fail → **miss** (`ok=false`, nil error). Do **not** return `ErrUnavailable` on `JsonGet`.
  - `holdsReplica` → `JInstall` then extract.
  - Non-replica → decode `ent.Value` in process; **do not** `JInstall`.

```mermaid
sequenceDiagram
  participant C as Client
  participant N as Non-owner
  participant O as Owner
  participant R as Replica
  C->>N: JsonSet(name, $.a, 1)
  N->>O: ApplyPut FlagJSONSet inbox Version=1
  O->>O: JSet (stored=local+1 under mutex) + PeekVersion + replicate FlagJSON
  O->>R: ApplyPut FlagJSON snapshot
  O-->>N: applied
  N-->>C: OK
  Note over R: JInstall only; ignore inbox flags
  C->>R: JsonGet(name, $.a)
  Note over R: HasJSON → local extract (may lag)
  C->>N: JsonGet(name, $.a)
  alt N holds replica copy
    N-->>C: local extract
  else non-replica
    N->>O: GetOrLoad(name)
    O-->>N: FlagJSON snapshot
    N-->>C: extract path
  end
```

**Hint-after-down (normative):** two `JsonSet`s of **different** paths while replica B’s Peer is down; then start B and wait for hint flush. The pending hint is the **latest snapshot** → B has **both** paths. Copy List’s ring/transport/down setup (`TestListHintAfterPeerDownKeepsBothPushes`). **Do** require both paths (this is why we chose snapshot). Do **not** copy Hash’s “do not require both fields.”

### What existing clients can assume

- CacheOnly / LoadThrough / Bloom / Set / ZSet / Geo / List / Hash / Counter unchanged if they never open `ModeJSON`.
- No new default node keyspace (`-demo-keyspace` stays `demo` / `tags` / `board` / `profile`).
- Rolling: do **not** register a `ModeJSON` keyspace until every node has the JSON `ApplyPut` branches. An old node would fall through `ApplyPutWithRingGen` to `AcceptIfNewer` and treat `Mode=9` as KV.

## Approach

### In-memory (`pkg/jsonx`)

Package **`pkg/jsonx`** (stdlib `encoding/json` clash). Same rationale as `pkg/listx` / `pkg/hashx`.

```go
package jsonx

type Path []Seg

type Seg struct {
    Key   string // object key; valid when !IsIndex
    Index int    // array index; valid when IsIndex
    IsIndex bool
}

var (
    ErrPath   = errors.New("jsonx: invalid path")
    ErrType   = errors.New("jsonx: type mismatch")
    ErrIndex  = errors.New("jsonx: array index")
    ErrJSON   = errors.New("jsonx: invalid json")
)

func ParsePath(s string) (Path, error)     // "" and "$" → empty Path (root)
func Decode(b []byte) (any, error)         // Decoder.UseNumber; reject trailing
func Encode(v any) ([]byte, error)         // compact; no HTML escape
func Equal(a, b []byte) bool               // Decode both (not json.Unmarshal); typed equal
func Get(doc any, p Path) (any, bool)
func Set(doc any, p Path, val any) (any, error) // returns new root; does not mutate doc
func Del(doc any, p Path) (any, bool, error)    // new root; ok=false if nothing removed
func Clone(v any) any                      // typed walk; keeps json.Number

func EncodeSet(path string, raw []byte) []byte
func DecodeSet(b []byte) (path string, raw []byte, err error)
```

**Decode (locked `UseNumber`):**

```go
func Decode(b []byte) (any, error) {
    if len(b) == 0 {
        return nil, ErrJSON
    }
    dec := json.NewDecoder(bytes.NewReader(b))
    dec.UseNumber()
    var v any
    if err := dec.Decode(&v); err != nil {
        return nil, ErrJSON
    }
    if dec.More() {
        return nil, ErrJSON
    }
    return v, nil
}
```

Integers survive `JsonGet` as JSON numbers (`json.Number`), not `float64` (`1e21` surprises). `true` / `false` / `null` / strings / objects / arrays are the usual `encoding/json` `any` tree (`map[string]any`, `[]any`). **`Decode("null")` returns Go `nil`.**

**Every decode path uses `Decoder.UseNumber`** — `Decode`, `Equal`, `JInstall`, rebuild `jCache` from `Value`. Never `json.Unmarshal` into `any` (that is `float64`).

**Encode (locked):** `json.Encoder` + `SetEscapeHTML(false)` + strip the trailing newline `Encode` adds. Compact (no indent). Object key order is Go `map` iteration — **`encoding/json` sorts map keys**, but do **not** rely on byte equality in tests: compare with `jsonx.Equal`. Document that `JsonGet` bytes may differ in key order / number spelling (`1` vs `1.0` is preserved by `json.Number`; `1` vs `01` is not, because `01` is invalid JSON).

**Clone / Set / Del / Equal (locked):** typed walk of `map[string]any`, `[]any`, `json.Number`, `string`, `bool`, `nil`. **No** `json.Marshal`/`Unmarshal` on the tree (that would drop `json.Number`). `Equal(a, b []byte)` is `Decode(a)` + `Decode(b)` then a typed walk (or `reflect.DeepEqual` on those trees) — **not** `json.Unmarshal`.

`Set`/`Del` clone first; the live store tree is not mutated unless the caller installs the returned root.

- Go `nil` is JSON **null**, not a missing document.
- `Set(nil, root, val)` → `val`.
- `Set(nil, non-root, val)` → `ErrType` (never `{"a":…}`, never `[]any`).
- `Del(nil, root)` → `map[string]any{}`, `ok=true`.
- `Del(nil, non-root)` → `nil`, `ok=false`.
- `Del` of root on any live doc → `{}`, `ok=true`.

Creating `{}` for a **missing name** is `JSet`’s job (`map[string]any{}` then `Set`), not `Set(nil, …)`.

**Inbox payload (locked):**

```text
FlagJSONSet Value = uvarint(len(path)) + path + raw JSON
FlagJSONDel Value = path bytes (no length prefix; the whole Value is the path)
```

`EncodeSet` / `DecodeSet`: one path + one raw JSON. Empty path is legal (`$`). Copy Hash `consumePair` (`pkg/hashx/hashx.go`: `n, w := binary.Uvarint(b)`; error only if `w <= 0`; `n` may be `0`).

**`DecodeSet` (locked):**

```go
v, w := binary.Uvarint(buf)
if w <= 0 { // truncated (w==0) or overflow (w<0) — NOT “empty path”
    return "", nil, err
}
rest := buf[w:]
if v > uint64(len(rest)) { // before make/slicing a huge n
    return "", nil, err
}
path := string(rest[:v]) // v==0 is OK: empty path ≡ $
raw := rest[v:]          // may be empty
```

- **`w <= 0`** is the only uvarint failure. **`v == 0` is an empty path**, not an error. `EncodeSet("", []byte(`{"a":1}`))` must round-trip.
- Empty JSON tail is **not** a `DecodeSet` error. Caller `jsonx.Decode` / `JSet` fails (`ErrJSON`). `applyJSONSet` has no empty-tail special case.

`ApproxWireBytes(v any) int64` = `len(Encode(v))` after a successful mutate (store already has the blob). Do not encode twice on the Get path.

### Store (`pkg/store`)

Last shipped bit is `FlagCounter` `1<<19` in `pkg/store/entry.go`. Confirm unused, then:

```go
FlagJSON    uint32 = 1 << 20 // value is encoded JSON document snapshot
FlagJSONSet uint32 = 1 << 21 // owner-inbox: path + JSON value
FlagJSONDel uint32 = 1 << 22 // owner-inbox: path
```

`Entry.IsJSON()` / `IsJSONSet()` / `IsJSONDel()`.

Live `jCache any` + `jDirty` on `lruItem`, mirroring `hCache` / `lCache`.

```go
// store.Store
JSet(key, path string, raw []byte, version uint64, expireAt int64, maxValue int) (applied, tooLarge bool)
JDel(key, path string, version uint64, expireAt int64) (ok, mutated bool)
JGet(key, path string) (json []byte, ok bool) // copy; missing path → false
HasJSON(key string) bool                      // live unexpired FlagJSON; not jCache != nil
JInstall(key string, blob []byte, version uint64, expireAt int64) bool // incoming > local
```

**`JSet` (locked).** Gate first; **only a successful apply mutates**.

1. Live non-JSON → `applied=false`; no write.
2. Live unexpired tombstone and `version <=` tombstone → `applied=false`; no write.
3. Decode `raw` (`jsonx.Decode`). Fail → `applied=false`.
4. Parse path. Fail → `applied=false`.
5. Missing / expired / tombstone with `version >` tombstone → **create**:
   - Root path (`$` / `""`): install `val` (may be Go `nil` = JSON `null`).
   - Non-root: `jsonx.Set(map[string]any{}, path, val)`. Index-first (`$[0]`) → `ErrType` → `applied=false`, **no insert**.
6. Live JSON: `jsonx.Set(clone, path, val)`. Live `null` is Go `nil`; non-root → `ErrType`. Type / index error → `applied=false`; **live tree unchanged**.
7. `blob, err := jsonx.Encode(newDoc)`. Fail → `applied=false`. (`Encode(nil)` is `null`.)
8. If `maxValue > 0 && len(blob) > maxValue` → `tooLarge=true`, `applied=false`; **do not mutate**.
9. Commit under this mutex: `Version = 1` on create (missing/expired) or `local.Version+1` when replacing live JSON / a superseded tombstone; `Flags=FlagJSON`; `Value=blob`; `jCache=newDoc` (**`nil` means JSON null**); `jDirty=false` (eager Value after encode); slide `ExpireAt` if `expireAt != 0`; cost; `MoveToFront`; `evictLocked`. Incoming `version` is **not** written (tombstone-gate floor only — step 2).

**`JDel` (locked).** Returns `(ok, mutated bool)` — List-pop shaped, **not** Hash `HDel`.

| Outcome | `ok` | `mutated` | Store write |
|---------|------|-----------|-------------|
| Missing / expired name | true | **false** | none (no insert) |
| Missing path / type-mismatch parent | true | **false** | none (version/TTL unchanged) |
| Tombstone `version <=` | false | false | none |
| Live non-JSON | false | false | none |
| Path parse fail | false | false | none |
| Child removed, or `$` (including already-`{}`) | true | **true** | tree + encode + **unique** `Version` under this mutex / `ExpireAt` |

1. Missing / expired → `(true, false)`, no insert (copy `HDel` “no insert”, but **do not** pretend a mutate happened).
2. Tombstone `version <=` tombstone → `(false, false)`. (`version` is a **tombstone-gate floor only**, not the stored snapshot version.)
3. Live non-JSON (including tombstone with `version >` tombstone) → `(false, false)`.
4. Parse path fail → `(false, false)`.
5. `jsonx.Del`. Missing path or non-root on `null` → `(true, false)`; **do not** write `Version` / `ExpireAt`.
6. Removed child, or path `$` / `""`: commit new tree + encode. `$` always yields encoded `{}` and **`mutated=true` even if the doc was already `{}`**. Slide `ExpireAt` if `expireAt != 0`. `Version = local.Version+1` (same rule as `JSet`; `JDel` never creates). Incoming `version` is **not** written.

**Stored version (`JSet` and `JDel`, locked — one formula):**

```text
stored = local.Version+1          // live FlagJSON, or replace tombstone after gate
stored = 1                        // JSet create (missing / expired; no local entry)
incoming version                  // tombstone-gate floor only
```

Do **not** write a pre-lock `jNextVersion` / `PeekVersion+1`. Do **not** use `max(local, incoming)+1` (that is a second version space and lets an in-flight `JsonSet` mint sit *below* a `JsonDel`). Two concurrent owner mutates (set/set, del/del, or **set overlapping del**) serialize on the store mutex: first writes `n+1`, second writes `n+2`.

Engine **must** replicate `PeekVersion` **after** `JSet`/`JDel` returns a mutate, not the candidate it passed in. `observeVersion` that same post-write version so later tombstone gates stay above it.

`version` may still be `PeekVersion+1` or `0` for the tombstone gate; it is **not** the fan-out version.

**`HasJSON` (locked):** copy `HasHash`’s **flag** gate — live, unexpired, not tombstone, `IsJSON`. **Not** `jCache != nil` (a live `null` has `jCache == nil` after decode). Do not require a successful decode.

**`jCache` (locked):** `jCache == nil` after a successful `Decode` / commit of `null` **is** JSON null. Rebuild-from-`Value` when the cache was cleared (`Set` / `AcceptIfNewer` nil `jCache` today the same way they nil `hCache` at `memory.go:167-168`). Peek helper: if `jDirty`, return `jCache` (nil = null); if `!jDirty && jCache == nil`, `Decode(Value)` (`UseNumber`) and store the result (nil = null).

**`JGet`:** `HasJSON` + extract. Root + `!jDirty` may copy `entry.Value`. Live `null` at `$` → `[]byte("null")`, `ok=true`. Corrupt / type miss → `ok=false`.

**`JInstall`:** same gate as `HInstall` / `CInstall` (`incoming > local`; equal ignore; tombstone `<=` blocks). `Decode` (`UseNumber`) fail → `false`. Replace with blob copy + `jCache` (nil if JSON null); `jDirty=false`.

**Flush (Get-hit safety):**

```go
func (m *Memory) flushJSONValueLocked(it *lruItem) {
    if it == nil || !it.jDirty || !it.entry.IsJSON() {
        return // 0-alloc; do NOT early-out on jCache==nil (that is JSON null)
    }
    blob, err := jsonx.Encode(it.jCache) // nil → []byte("null")
    if err != nil {
        return
    }
    // same cost adjust as flushHashValueLocked
}
```

Call from `Get` / `Peek` next to `flushHashValueLocked`. **Must be 0-alloc** when `!jDirty || !IsJSON`. After `JSet`/`JDel` we write Value eagerly (`jDirty=false`), so the flush is a no-op on the JSON write path too. KV Get-hit must not allocate inside this helper.

`Set` / `AcceptIfNewer` clear `jCache`/`jDirty` like the other caches.

Protect live `FlagJSON` in `lruVictim` (`memory.go` today lists Bloom/Set/ZSet/Geo/List/Hash/Counter).

```go
func (e *Engine) applyJSONSet(ks *ksRuntime, name string, inbox []byte, expireAt int64) bool {
    path, raw, err := jsonx.DecodeSet(inbox)
    if err != nil {
        return false
    }
    if expireAt == 0 {
        expireAt = e.expireAt(ks.cfg.TTL)
    }
    max := e.maxValueSize
    if ks.cfg.MaxValueSize > 0 {
        max = ks.cfg.MaxValueSize
    }
    cur, _ := ks.store.PeekVersion(name)
    gate := cur + 1 // tombstone floor only; JSet assigns the stored version
    ok, tooLarge := ks.store.JSet(name, path, raw, gate, expireAt, max)
    if !ok || tooLarge {
        return false
    }
    ver, _ := ks.store.PeekVersion(name) // unique version JSet just wrote
    ks.observeVersion(name, ver)
    e.jReplicateSnapshot(ks, name, ver, expireAt)
    return true
}

func (e *Engine) applyJSONDel(ks *ksRuntime, name string, path []byte, expireAt int64) bool {
    if expireAt == 0 {
        expireAt = e.expireAt(ks.cfg.TTL)
    }
    cur, _ := ks.store.PeekVersion(name)
    gate := cur + 1 // tombstone floor only; JDel assigns the stored version
    ok, mutated := ks.store.JDel(name, string(path), gate, expireAt)
    if !ok {
        return false
    }
    if !mutated {
        return true // missing name / missing path / type-mismatch: ACK, no fan-out
    }
    ver, _ := ks.store.PeekVersion(name) // unique version JDel just wrote
    ks.observeVersion(name, ver)
    e.jReplicateSnapshot(ks, name, ver, expireAt)
    return true
}
```

`jReplicateSnapshot`: `Peek` + `IsJSON` + `replicate` `{Flags: FlagJSON, Value, Version: ver, ExpireAt}` — copy `lReplicateSnapshot`.

`jFetchOwner`: copy `cFetchOwner` / `hFetchOwner` with `IsJSON` + `jsonx.Decode` + optional `JInstall`.

## Key Decisions

| Decision | Lock | Rationale |
|----------|------|-----------|
| Name | `JSON` / `ModeJSON` / `JsonSet` `JsonGet` `JsonDel` | Same naming as Geo/Hash |
| API surface | three verbs + `Delete(name)` | Smallest complete document; skip `JsonType` |
| Fan-out | **`FlagJSON` snapshot only** | `hintID` is `(ks, name)`; item flags would drop other paths |
| hintID | **unchanged** | Out of scope |
| Owner-inbox | `FlagJSONSet` / `FlagJSONDel` via ApplyPut | ACK-only; List push pattern; owner applies the **op** |
| Replica apply | install snapshot only; **ignore** inbox flags | Same as List LPush |
| Peer RPCs | **none new** | No return payload |
| Reads | `HasJSON` → local extract; else GetOrLoad | Match GeoPos / Hash / Counter; document replica lag |

## Security & privacy

No new auth surface. Document names/paths/values ride the existing Cache gRPC (TLS) and Peer ApplyPut (mTLS). Do not log document bodies (often PII). Limits (`MaxKeyLen` on name/path; `MaxValueSize` on value **and** encoded doc; `MaxBytes` may overshoot one live document) are the DoS bound. Same tenant isolation: keyspace config is local and must match across nodes.

Owner **store mutex** serializes `JSet` / `JDel` **and** assigns `stored = local.Version+1` (or `1` on create). There is **no** extra engine owner-mutate mutex — same as Hash/List. Two clients mutating the same name (set/set, del/del, or set overlapping del) apply in store-lock order; successive snapshots have distinct versions so `JInstall` cannot drop the later one. A client that retries `JsonSet` after a timeout may double-apply (last write wins at that path). SuperCache does not have request ids.

## Observability

Reuse existing fan-out / hint / `staleSkip` / store hit-miss counters. No new required metrics in v1. Optional later: document-byte histogram. Wrong-mode, bad JSON/path, and oversize map through `grpcmap`.

## Rollout / rollback

- Opt-in: nothing happens until an operator registers a `ModeJSON` keyspace on **every** node.
- Deploy the JSON build cluster-wide first; then `UpdateKeySpace`.
- Rollback: stop writing Json*; `Delete(name)` or drop the keyspace. No on-disk format.
- No feature flag (mode is the flag).
- Example is in-process only; it does not change node defaults.

## Open points (resolved)

1. **Naming:** **ModeJSON** / **JsonSet** / **JsonGet** / **JsonDel**.
2. **Fan-out:** **snapshot `FlagJSON` only**; inbox flags never go to replicas.
3. **Return path:** none; ApplyPut inbox + snapshot (List push).
4. **Path language:** `$` / `.ident` / `["k"]` / `[n>=0]`; after `[`, `"` → **`encoding/json` only** (no `strconv.Unquote`) else index; `$["a\/b"]` → `a/b`; no *unquoted* spaces; no `..` / `*` / filters / negatives.
5. **Parents:** create objects; never arrays. `Set(nil, index/key)` is `ErrType`.
6. **Empty-until-delete:** `JsonDel $` → live `{}` (`mutated=true` even if already `{}`); missing name / missing path `mutated=false`.
7. **Numbers:** **`Decoder.UseNumber` every decode**; Clone/Equal typed walk; no `Unmarshal`.
8. **Size:** encoded doc `> MaxValueSize` aborts the mutate. Engine `ErrValueTooLarge` → gRPC InvalidArgument via grpcmap.
9. **Version:** **one rule** for `JSet` and `JDel` — `stored = local.Version+1` (or `1` on `JSet` create) under the store mutex; incoming `version` is tombstone-gate only; engine fans out `PeekVersion` after the write. `applyJSONSet` matches `applyJSONDel`. Concurrent set overlapping del is a required test.
10. **Live `null`:** `HasJSON` true; `jCache==nil` after decode is null, not missing.
11. **`JsonType`:** **not v1**.
12. **Example:** **same PR**, `examples/json`, name `user`; values are raw JSON (`[]byte("\"Paris\"")`).
13. **Demo KS:** **not** in this PR.
14. **CLUSTER_FLOWS:** table + E11 `JsonGet` + OPS; JsonSet not on E10.
15. **Hint test:** both paths present after snapshot replay.
16. **Flags:** `1<<20` / `1<<21` / `1<<22`.
17. **`DecodeSet`:** Hash `v, w := binary.Uvarint`; `w<=0` error; `v==0` empty path OK (`EncodeSet("", {"a":1})` round-trips).

## Rejected alternatives

| Idea | Why not |
|------|---------|
| CacheOnly blob rewritten by the app | Concurrent path updates LWW the whole document |
| Hash fields holding JSON text | Flat only; no arrays / types / `$.a.b[0]` |
| Item-level `FlagJSONSet` to replicas | Lost hints drop the other path; `hintID` is `(ks, name)` |
| Change hintID in this PR | Touches global hint path; separate design |
| Client-built snapshot ApplyPut to owner | Two writers clobber; owner must apply the **op** |
| New Peer RPC | JsonSet/JsonDel are ACK-only; ApplyPut suffices |
| Full JSONPath | Filters / `..` / `*` are a different product |
| Auto-create arrays | Ambiguous length/padding; ARRAPPEND is a follow-up |
| `float64` decode | `1<<60` and integers > 2^53 become lies |
| `JsonType` / NUMINCRBY / ARRAPPEND in v1 | Keeps the first PR small; snapshot would make incr/append safe later |
| Default JSON demo keyspace | Hash already added `profile` |
| Byte-equal JSON tests | Map key order / spacing is not a contract |
| `JSet` pre-lock `jNextVersion` + `JDel` `max(local, incoming)+1` | Two version spaces; in-flight set can commit below a del; replica `JInstall` drops the later snapshot |
