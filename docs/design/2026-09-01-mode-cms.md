# Count-Min Sketch type (`ModeCMS`) — named frequency of any item

**Author:** SuperCache
**Status:** approved
**Branch (later):** `feat/mode-cms`
**Date:** 2026-09-01

## Overview

SuperCache can count one name exactly (`ModeCounter`), estimate how many **distinct** items have been seen (`ModeHLL`), name the head of an observation stream (`ModeTopK`), and store an exact unbounded scored set you write scores into (`ModeZSet`). It cannot answer “approximately how many times have we seen **this** item?” when the item set is huge, the caller **names** the item at query time, and storing one counter per distinct item (or keeping every identity in a heap) is the wrong shape.

`ModeCMS` is a **named, fixed-size Count-Min Sketch**. Callers poke a named sketch with items (`CMSIncr`; **`n` defaults to 1**). `CMSQuery(name, item)` returns the min of *d* hashed cells. Items are **hashed, not stored**. Memory is **O(d·w)** — not O(distinct), not O(K). The estimate is an **overestimate only**. v1 is Cormode–Muthukrishnan CMS, stdlib-only, ACK-only, List/HLL/TopK-class **snapshot fan-out**. It is **not** RedisBloom `CMS.*`. There is **no `CMSAdd`**. `CMSIncr` does **not** return the new estimate (that would be a Peer RPC, like `CounterIncr`).

The motivating product is the gap [ModeTopK](./2026-08-31-mode-topk.md) already named: Space-Saving on [`examples/billboard`](../../examples/billboard/) `plays`/`hot` **cannot** answer “how many plays did evicted `t003` get?” A sibling ModeCMS keyspace `plays-count` (same name `hot`) can. Official SoT boards stay `LoadThrough` `charts`. **No** new `examples/cms` package. **No** retrofit of [`examples/ratelimit`](../../examples/ratelimit/) (that demo is exact `Incr` returning *n*).

This is new product behavior on the data path. Full path in [WORKFLOW.md](../WORKFLOW.md): design → review → (after approval) tests → code → bench → PR. **No tests or implementation until this draft is approved** (`looks good` / `do it` / `implement`).

## Problem

A radio-scale play stream (and any high-cardinality observation stream) has a query ModeTopK refuses: **point frequency of an item you name**, including items that lost the heavy-hitter table.

| Mode | Shape | Why it is not CMS |
|------|--------|-------------------|
| `ModeCounter` | Exact `int64` of **one** name | One sketch per item (`plays:t003`) explodes names. The caller must have created that name. Cannot share a fixed blob across a huge item set. |
| `ModeTopK` `TopKList` | Bounded heavy-hitter **filter** | Names the head. Space-Saving counts only for items **in** the table. “Not in table” is **not** zero — that is why TopK omitted `TopKQuery` / `TopKCount` ([2026-08-31-mode-topk.md](./2026-08-31-mode-topk.md)). Evicted `t003` (true 100 plays) is gone. |
| `ModeHLL` | Approx **distinct cardinality** | Answers “how many unique tracks were played?” with **no identities** and **no per-item counts**. `HLLAdd` of a seen item is idempotent. |
| `ModeZSet` `ZAdd` | Exact, **unbounded** scored set | You **write a score**. The whole zset is one LRU entry. Station-day distinct overflows `DefaultMaxValueSize` (1 MiB). No `ZINCRBY` in v1. |
| `ModeHash` | Field → blob | No increment. `HINCRBY` was rejected: hint coalesce drops increments ([2026-08-20-mode-hash.md](./2026-08-20-mode-hash.md)). |
| `ModeSet` / `ModeBloom` | Membership | No counts. Set is O(distinct). Bloom is a bit. |
| `ModeBitmap` `BitCount` | Packed addressable bit vector | Counts **set bits**, not hashed-item frequency. Offset *n* is a bit address. |
| `ModeList` / `ModeJSON` / `ModeGeo` | Sequence / document / points | Wrong shape. |
| CacheOnly / LoadThrough | Opaque KV | `Put` LWW-replaces a blob. A client-side map in the value is a lost-update race. |

Yesterday’s TopK design locked the uniqueness gap this PR fills:

> Count-Min Sketch is **not shipped**. CMS answers “approx count of an item you **name**”; it does not return the winner list unless a second structure (heap) tracks identities.

**CMS uniqueness (locked):**

- **Counter** is the exact `int64` of **one** name.
- **HLL** is approx **distinct cardinality** of hashed items; no per-item counts; no identities.
- **TopK** is a bounded heavy-hitter **filter**; names the head; Space-Saving counts only for items **in** the table; “not in table” is not zero.
- **ZSet** is an exact unbounded scored set you **write scores into**.
- **CMS** is a fixed-size frequency sketch; query **any** item you name; overestimate only; items are **hashed, not stored**; memory independent of stream cardinality.

`Get`/`Put` cannot express it. `Get` returns a blob; `Put` replaces a blob. A sketch has a **name** plus an **item** to hash. Mapping `Put(name, item)` would overload Put and still have no `Query`.

### Dedicated use case: billboard complement (evicted-track frequency)

[`examples/billboard`](../../examples/billboard/) already has the play stream. ModeTopK `plays`/`hot` at K=10 keeps the locked honest chart (`t001`=200, `t002`=150, `t495`–`t500` at 109, …). Replace-min **evicts** `t003`/`t004`/`t005` (true counts 100/80/60). The UI can list the head; it cannot answer “how many plays did `t003` get?”

This PR **adds a ModeCMS sibling** on the same cluster — not a follow-up, not a new `examples/cms`, not a ratelimit rewrite.

| Story | Keyspace | Job | This PR |
|-------|----------|-----|---------|
| Official boards | `LoadThrough` `charts` | Precomputed SoT JSON | **Keep** |
| Live plays / trending-now | `ModeTopK` `plays` | Observations: `TopKAdd` / `TopKList` ≤ K | **Keep** |
| Point frequency of any play id | **`ModeCMS` `plays-count`** | Same stream: `CMSIncr` per play (`n` defaults to 1), `CMSQuery(hot, t003)` | **Add** |
| Exact per-window limiter | `ModeCounter` (`examples/ratelimit`) | `Incr` returns *n*; compare to a limit | **Not this PR** |

A station observes plays:

- Catalog: **500** play ids `t001`–`t500`; scripted stream N = **1220** (`honestPlayStream` in [`examples/billboard/plays.go`](../../examples/billboard/plays.go)).
- Writes: each play is **one `TopKAdd` and one `CMSIncr(..., 1)`** (`plays`/`hot` and `plays-count`/`hot`). HTTP `POST ?n=` is **n `TopKAdd`s + one `CMSIncr(item, n)`** (one 64 KiB CMS fan-out, not n). Fail-closed on first error, **no** cross-keyspace rollback. No score.
- Reads: chart remains `TopKList`. Point query `GET /v1/counts/hot?track=t003` → HTTP **200** `present=true` + `count ∈ [100,116]` after eviction.
- Replica `CMSQuery` may lag by **one fan-out RTT**. Acceptable for a count tile.
- Windows: **name** `hot:2026-08-31-15` (README only; scripted demo stays `hot`). No decay.

Memory is the product reason:

| Sketch | What is stored | 500 tracks (`t001`, 4 B) | 100k distinct / day |
|--------|----------------|--------------------------|---------------------|
| `ModeCounter` per item | one `int64` + envelope **per name** | ≈ 500 × ~80 B ≈ **40 KiB** and **500 names**; must create each name | ≈ **8 MiB** + 100k names |
| `ModeTopK` K=10 | ≤ 10 identity slots | ~60 B typical; **cannot** answer evicted `t003` | **same ~60 B**; still cannot query the tail |
| `ModeHLL` | 12 KiB registers | 12 KiB; **no** per-item counts | **same 12 KiB**; no identities |
| `ModeZSet` of every play-id | 8 B score + uvarint(len) + member per distinct | ≈ **6.5 KiB** and grows | ≈ **1.24 MiB** — over 1 MiB default |
| `ModeCMS` d=4, w=2048 | `4 × 2048 × 8` = **65536** bytes | **64 KiB**; query any named item | **same 64 KiB** |

Classic CMS (depth 4, width 2048) overestimate allowance is `ε·‖a‖₁` with `ε = e/w ≈ 0.001327`, `δ = e^{-4} ≈ 1.83%`. For the locked stream `‖a‖₁ = 1220`, `εN ≈ 1.62`. So `CMSQuery(t003)` is typically **100–102** (true 100) — the number TopK forgot.

Be honest: CMS **overestimates**; it cannot list items; it is not a ranking type; it is not a rate-limit *enforcer* by itself (you still compare an estimate to a threshold, and ACK-only `CMSIncr` does not return *n*).

Dedicated example (same implementation PR): **update [`examples/billboard`](../../examples/billboard/)**. **No** new `examples/cms`. Keep the kitchen sink; add only the frequency keyspace + query.

## Goals & Non-Goals

### Goals

- Named, keyspace-scoped Count-Min Sketch with two verbs + `Delete(name)` (`CMSIncr`, `CMSQuery`). `n` defaults to 1 — no `CMSAdd`.
- Fixed **64 KiB** memory regardless of stream cardinality.
- Query **any** item the caller names; overestimate only; items hashed, not stored.
- Owner ACK + async `FlagCMS` snapshot to RF−1. No new Peer RPC.
- Present-bit on the **name** (missing ≠ estimate 0).
- Update [`examples/billboard`](../../examples/billboard/) in the type PR: dual-write `plays-count`, query evicted `t003`.
- Product docs in that same PR (stop saying “CMS is not shipped”).

### Non-goals

- RedisBloom / Redis `CMS.INITBYDIM` / `CMS.INITBYPROB` / `CMS.INCRBY` / `CMS.QUERY` / `CMS.MERGE` / `CMS.INFO` **numeric or wire parity**. Different hash (they use Murmur). SuperCache verbs are `CMSIncr` / `CMSQuery`. `CMSIncr` is ACK-only and does **not** return the new estimate (Redis `CMS.INCRBY` is fire-and-forget too; SuperCache `ModeCounter` `Incr` is the type that returns *n*).
- A separate `CMSAdd` verb. `CMSIncr` with **`n` default 1** is +1.
- Decrement / signed delta. `n` is `uint64`. **`n == 0` means 1** (proto3 default; no empty-create, no +0 touch). No `CMSDecr`.
- Configurable `CMSWidth` / `CMSDepth` as keyspace knobs. v1 locks d=4, w=2048 (one blob size, like HLL `p=14`).
- `CMSMerge`, `CMSInit` empty, `CMSInfo`, top-k-from-CMS, point-delete, decay, Conservative-Update, Count-Mean-Min.
- Multi-key unions / `CMS.MERGE` of two names (PLAN §1 already excludes multi-key atomicity).
- A new `examples/cms` mini-walkthrough (the real billboard already has the stream).
- Retrofitting [`examples/ratelimit`](../../examples/ratelimit/) (that demo is exact `Incr` returning *n*; CMS is the wrong enforcer).
- Replacing ModeTopK `plays` with CMS (CMS cannot name the head).
- A default `-demo-keyspace` CMS keyspace on the stock node (same as HLL/TopK). Optional follow-up only.
- Changing RF, tombstones, **hint identity** (`hintID` stays `(ks, name)` except `FlagBloomAdd` in `internal/peer/hints.go`), or existing Get/Put/Delete / Bloom / Set / ZSet / Geo / List / Hash / Counter / JSON / Bitmap / HLL / TopK contracts.
- Persistence / WAL / Redis dump import.
- scbench YAML cells.
- A new Peer RPC.
- CRDTs, streams.

CMS as a SuperCache **mode** is in scope. **Do not add CMS to PLAN §1 non-goals.** PLAN §1’s “HyperLogLog” line is “not RESP / not a Redis clone”; RedisBloom `CMS.*` is not even in that sentence. Multi-key merge stays out.

## Why not item-level fan-out (locked)

Two `CMSIncr`s of **different** items commute at the cell level (both are increments of possibly-overlapping cells), but `hintID` is still `(ks, name)`:

```go
// internal/peer/hints.go
func hintID(ks, key string, ent store.Entry) string {
    if ent.IsBloomAdd() {
        return ks + "\x00" + key + "\x00" + string(ent.Value)
    }
    return ks + "\x00" + key
}
```

A second mutate of the same name **replaces** the pending hint. Item-level `FlagCMSIncr(item)` on the replica **wire** would drop an earlier *other* item — the List / JSON / Bitmap / HLL / TopK snapshot reason, and the Hash caveat we refuse ([2026-08-20-mode-hash.md](./2026-08-20-mode-hash.md)). Bloom is the **only** exception because `hintID` includes the item.

**v1 wire:** every owner mutate fans out a **full dense counter blob** (`FlagCMS` `1<<29`) at the post-op version. Hint coalesce keeps the newest snapshot — that is correct. Network is a fixed **64 KiB** per incr (5.3× HLL’s 12 KiB). Operational note: QPS × 64 KiB × (RF−1) replica traffic; same class as HLL, larger constant.

**No `FlagCMSIncr` on the replica wire.** That flag is **owner-inbox only** (List `FlagListLPush` / `FlagListRPush` in `pkg/engine/list.go`; HLL `FlagHLLAdd` in `pkg/engine/hll.go`; TopK `FlagTopKAdd` in `pkg/engine/topk.go`; Bitmap `FlagBitmapSet` in `pkg/engine/bitmap.go`).

Rejected for v1: per-item replica apply; hintID change; op-log + snapshot-on-gap; Hash-class item-level with a “do not require both items” caveat; cell-wise sum-merge or min-merge of sketches (handoff is LWW — see [Handoff is LWW, not merge](#handoff-is-lww-not-merge-locked)).

## Contract

### API (new; existing verbs unchanged)

On `pkg/engine.Engine`, `pkg/client.Client`, Cache proto, and **`cmd/sc`** (same PR as the type):

| Call | Meaning |
|------|---------|
| `CMSIncr(ks, name, item []byte, n uint64)` | Observe `item` **n** times (+n into *d* cells). **`n == 0` means 1.** Creates the sketch if missing. **ACK-only.** Does **not** return the new estimate. |
| `CMSQuery(ks, name, item []byte) (est uint64, ok bool, err)` | Min of *d* cells. Missing **name** → `ok=false`, `est=0`. Live sketch (including estimate 0 for an unseen item) → `ok=true`. |
| `Delete(ks, name)` | Existing Delete: whole-sketch tombstone. |

```go
CMSIncr(ctx context.Context, keyspace, name string, item []byte, n uint64) error
CMSQuery(ctx context.Context, keyspace, name string, item []byte) (n uint64, ok bool, err error)
```

No `CMSAdd`. Callers who want +1 pass `n=0` or `n=1` (both mean 1).

- `name` is the sketch identity; ring owner = `Owner(name)`. Validated with `validateKey` + `validateKeyLen` (per-keyspace `MaxKeyLen` applies to **name**).
- `item` is `[]byte`. **Empty item → `ErrInvalidArgument`** (`empty cms item`), same as List / Bloom / Set / HLL. Item length is bounded like Bloom / List / HLL (`pkg/engine/bloom.go`, `pkg/engine/list.go`, `pkg/engine/hll.go`): `len(item) > e.maxKeyLen` → `ErrKeyTooLarge`. Items are **hashed, not stored** — this is **not** TopK’s `validateKeyLen` / `itemMax` (TopK stores identities).
- `CMSIncr` is ACK-only. SuperCache does **not** return the new estimate. A return payload would need a new Peer RPC (`CounterIncr` class). Do not add one. Callers that need the estimate issue a later `CMSQuery` (may lag one fan-out RTT on a replica).
- `n` is `uint64`. **`n == 0` means 1** (proto3 omitted field is 0; CLI omits n → 1). Effective delta is `n` if `n ≥ 1`, else `1`. No decrement, no signed delta, no +0 touch, no empty-create.
- Each **owner** `CMSIncr` that applies assigns a **new stored version under the store mutex** (JSON/Bitmap/HLL/List/Counter/TopK rule — [2026-08-25-list-counter-version.md](./2026-08-25-list-counter-version.md)) and refreshes whole-sketch `ExpireAt` from keyspace `TTL` (`0` = none) — scheme B. ApplyPut paths use inbound `expireAt`, or `e.expireAt(TTL)` when the wire value is `0`. The inbound ApplyPut `Version: 1` on inbox flags is **not** the stored snapshot version.
- `CMSIncr` of an already-seen item **still** applies: the *d* cells increment, that item’s estimate +delta, new version, TTL slide, snapshot fan-out. There is no “unchanged → skip” path. Same as `HLLAdd` of a seen item / `TopKAdd` of a resident slot.
- Overflow — **any of the *d* hashed cells would wrap** (`cell > MaxUint64 - delta`) — → `ErrInvalidArgument`, **no wrap**, sketch **unchanged** (Counter / TopK rule). Wrapping a cell to 0 would **underestimate** and break the CMS guarantee.
- Get/Put on `ModeCMS` → `ErrInvalidArgument` (`use CMSQuery` / `use CMSIncr`).
- CMS* on non-`ModeCMS` → `ErrInvalidArgument`.
- Cross-mode misuse (CMSIncr on ModeTopK, TopKAdd on ModeCMS, HLLAdd on ModeCMS, …) → `ErrInvalidArgument`.
- `CMSQuery` empty item → `ErrInvalidArgument` (validate first, even if the name is missing).
- `CMSIncr` empty item → `ErrInvalidArgument`.

**Not in v1:** `CMSAdd`, `CMSMerge`, `CMSInit`, `CMSInfo`, decrement, width/depth knobs, top-k-from-CMS, Redis CMS names, a Peer RPC that returns the new estimate.

### Present-bit vs Redis 0 (locked)

Redis `CMS.QUERY` of a missing key is an error / 0 depending on module version. SuperCache keeps a **present-bit** on name identity, matching Hash / List / Counter / JSON / Bitmap `BitGet` / HLL `HLLCount` / TopK `TopKList`:

| State | `HasCMS` | `CMSQuery(item)` |
|-------|----------|------------------|
| Missing name / expired / tombstone | false | `n=0`, **`ok=false`**, nil error |
| Live sketch, any estimate of `item` (including 0 for an unseen item) | **true** | estimate, **`ok=true`** |
| Live sketch after first add of `item` | true | ≥ 1, `ok=true` |
| Live sketch after the same item twice | true | previous + 1 (not HLL-idempotent), `ok=true` |
| Live all-zero blob (install only; owner never produces one) | **true** | 0, **`ok=true`** |

A live CMS stays **present** until `Delete(name)`, even if every query returns 0. `CMSQuery` of missing **name** and of live-estimate-0 are both `n=0`; callers that need the distinction use `ok` or `HasLocal`.

`sc cmsquery` prints the decimal count when `ok=true`, `(nil)` + exit 1 when `ok=false` (copy `cget` / `hllcount`).

Do **not** return `ErrUnavailable` on `CMSQuery`. Owner-down / `GetOrLoad` failure / `!Found` / `!IsCMS` → miss (`ok=false`, `n=0`, nil error). Same as `hllFetchOwner` / `topkFetchOwner` / `bFetchOwner`.

### Empty-until-delete (locked)

Prefer empty-until-delete (same spirit as Hash / List / Counter / JSON / Bitmap / HLL / TopK):

| Op | Result |
|----|--------|
| First `CMSIncr` of a missing name | **Creates** a dense 64 KiB sketch; `HasCMS` true; `CMSQuery(item)` ≥ delta (`n==0` → delta 1) |
| `CMSIncr` of an already-seen item | Sketch stays live; that item’s estimate +delta; new version + TTL slide |
| `CMSIncr(..., 0)` | Same as `n=1` (not a reject, not a touch, not empty-create) |
| There is no “CMS create empty” / “CMS clear” verb | First incr creates; `Delete(name)` is the only drop |
| Live estimate 0 (zero blob installed, or query of an unseen item) | Name stays until `Delete(name)` |
| `CMSIncr` never calls `Delete(name)` | Incrementing is not a tombstone |

### Size / DoS (locked)

The stored blob is a **fixed** 64 KiB (`cmsx.DenseSize` = 65536). That is `<< keyspace.DefaultMaxValueSize` (1 MiB).

```text
dense = Depth * Width * 8 = 4 * 2048 * 8 = 65536
max   = ks.MaxValueSize > 0 ? ks.MaxValueSize : e.maxValueSize
if max > 0 && dense > max                     → ErrValueTooLarge, no mutate
```

- **Initiating node** rejects `CMSIncr` when `max < DenseSize` **before** apply or `ApplyPut` forward (so clustered clients get `ErrValueTooLarge`, not a swallowed `!applied`).
- Owner `CMSIncr` also checks; `tooLarge=true`, **no mutate**.
- Inbox apply that still overflows (race on `MaxValueSize`, corrupt inbox) → `applied=false`. ACK-only `ApplyPut` cannot carry `ErrValueTooLarge`; the non-owner maps `!applied` to `ErrInvalidArgument` (`cms add rejected`). Owner-hit / single-node path **does** return `ErrValueTooLarge`.
- `UpdateKeySpace` / `Config.Validate`: `ModeCMS` with `MaxValueSize > 0 && MaxValueSize < 65536` **fails validation** (size is fixed; fail fast — same as HLL 12288, unlike Bitmap / TopK whose size depends on offset / K).
- `MaxBytes` may still **overshoot** one live `FlagCMS` (same as Set/Geo/List/Hash/JSON/Bitmap/HLL/TopK). One 64 KiB sketch is allowed to sit in an LRU that is slightly over budget. Do **not** fail `Validate` when `MaxBytes < 65536`.
- Incoming snapshot `len(blob) != DenseSize` → `CMSInstall` rejects (`applied=false`). No truncate, no pad.

Item DoS is the existing `e.maxKeyLen` cap (items are not stored).

### Keyspace

New mode `keyspace.ModeCMS` (next iota after `ModeTopK`). `Mode.String()` **must** return `"CMS"` (else `/keyspaces` prints `Mode(13)`).

Current iota (`pkg/keyspace/config.go`): `LoadThrough=0` … `ModeTopK=12`. `ModeCMS=13`.

| Field | Role |
|-------|------|
| `MaxBytes` | Cost budget. Live `FlagCMS` is LRU-protected; one sketch may **overshoot** |
| `TTL` | Expires the **whole** sketch; owner `CMSIncr` **slides** `ExpireAt` (scheme B) |
| `NegativeTTL` | Ignored |
| `TombstoneTTL` | On `Delete(name)` |
| `ReplicationFactor` | Same as KV / ModeHLL / ModeTopK |
| `MaxKeyLen` | Bounds `name`. Item bound is engine `e.maxKeyLen` (hashed, not stored) |
| `MaxValueSize` | Must be `0` (engine default 1 MiB) or `≥ 65536`. Bounds the **counter blob** |

No `CMSWidth` / `CMSDepth` / `CMSEpsilon` knob. Do not reuse `BloomBits` or `TopKSize`. `ConfigHash` already includes `Mode`; no new hash field in v1.

### Replication (locked: snapshot like List / JSON / Bitmap / HLL / TopK)

| Hop | Payload |
|-----|---------|
| Client → any node → **owner** | `ApplyPut` `FlagCMSIncr` (`uvarint(delta) \|\| item`) if this node is not owner. `n==0` is encoded as `1`. |
| Owner → **replicas** | `FlagCMS` full snapshot after the op (dense 64 KiB + version + expire) |
| Handoff / `GetOrLoad` | `FlagCMS` install if incoming version **>** local (equal = ignore; tombstone blocks if incoming ≤ tombstone). **Not** cell-wise min. **Not** cell-wise sum. |

`CMSIncr` is ACK-only — **no new Peer RPC**. Inbox flags + snapshot fan-out (HLL / TopK / List **push** / JSON `JsonSet` / Bitmap `BitSet` pattern). `CMSQuery` never needs a Peer RPC: local extract or `GetOrLoad`.

**Inbox payload (locked — one flag, n in the value):**

```text
uvarint(n)  item[rest]
```

- Empty `item` after the uvarint → owner apply `applied=false`.
- `n == 0` in a decoded inbox is treated as **1** (same as the engine API). Encode always writes the **effective** delta (`n` if `n≥1`, else `1`).
- No length prefix on the item (rest of `Value` is the item). One inbox flag — do **not** spend `1<<31`.
- A corrupt / truncated uvarint → `applied=false`.

**Version assignment (locked — one rule for store `CMSIncr`):**

Assign the stored snapshot version **inside the store mutex**. There is **no** second version space (`cmsNextVersion` / `max(local, incoming)+1` is **not** used).

```text
if missing / expired (no live entry):     stored = 1          // create
if live FlagCMS or replacing tombstone:   stored = local.Version + 1
incoming `version` argument:              tombstone-gate floor only
                                          (reject if live tombstone && incoming <= tombstone.Version)
```

- Do **not** write the engine’s pre-lock `PeekVersion+1` as `Entry.Version`.
- Engine fans out **`PeekVersion` after the store write** (then `observeVersion` that same value). Never fan out the candidate passed in.
- Concurrent owner `CMSIncr`s serialize on the store mutex → distinct versions → `CMSInstall` (`incoming > local`, equal = ignore — same as `HLLInstall` / `TopKInstall` / `BInstall` / `JInstall` at `pkg/store/memory.go`) cannot drop the later snapshot.

**Owner-inbox vs replica-apply (locked — copy HLL / TopK / List / JSON / Bitmap, not Hash / Bloom):**

- Non-owner: `Transport.ApplyPut` `{Flags: FlagCMSIncr, Value: uvarint(n)\|\|item, Version: 1}`.
- Owner `ApplyPut` of that flag: **apply the op** (store `CMSIncr` first). Pass `PeekVersion+1` (0→1 if missing) **only** as the tombstone-gate floor. Do **not** use inbound `Version: 1` as the stored version. If the store reports a mutate, `ver, _ := PeekVersion(name)` then `ks.observeVersion(name, ver)` + `cmsReplicateSnapshot(..., ver, ...)`.
- Replica `ApplyPut` of `FlagCMSIncr`: **ignore** (`return false, nil`) if this node is not owner — same guard as `IsHLLAdd` / `IsTopKAdd` / `IsListLPush` / `IsJSONSet` / `IsBitmapSet` in `pkg/engine/engine.go` `ApplyPutWithRingGen`. Do not send inbox flags to replicas.
- `FlagCMS` → `CMSInstall` version gate only.

**Owner-local `CMSIncr`:** same as inbox apply — store first, fan out `PeekVersion` after write.

**Non-owner `applied=false`:** initiating node already rejected empty / oversize **item** and `DenseSize > max`. Owner reject (tombstone, non-CMS entry, uint64 overflow, bad inbox) surfaces as `ErrInvalidArgument` (`cms incr rejected`). Encoded `ErrValueTooLarge` is guaranteed on the **owner-hit / single-node** path.

**Reads (locked: same as `hllFetchOwner` / `topkFetchOwner` / `bFetchOwner`):**

- If `HasCMS` local → extract `cmsx.Query` from the **local** blob. Replica snapshot may **lag by one fan-out RTT**. **Do not** owner-forward a local hit.
- Else if this node is owner → missing sketch → `ok=false`, `n=0`.
- Else → `cmsFetchOwner` (copy of `hllFetchOwner`):
  - `GetOrLoad` RPC error / owner down / `!Found` / `!IsCMS` → **miss** (`ok=false`, `n=0`, nil error). Do **not** return `ErrUnavailable` on reads.
  - `holdsReplica` → `CMSInstall` then query.
  - Non-replica → `cmsx.Query(ent.Value, item)` in process; **do not** `CMSInstall`.

Owner down on `CMSIncr` → `ErrUnavailable` (no ACK authority), same as Put / HLLAdd / TopKAdd / BitSet / JsonSet. Do not apply locally.

```mermaid
sequenceDiagram
  participant C as Client
  participant N as Non-owner
  participant O as Owner
  participant R as Replica
  C->>N: CMSIncr(name, item, n)
  N->>O: ApplyPut FlagCMSIncr inbox uvarint(n)+item Version=1
  O->>O: CMSIncr (stored=local+1 under mutex) + PeekVersion + replicate FlagCMS
  O->>R: ApplyPut FlagCMS snapshot
  O-->>N: applied
  N-->>C: OK
  Note over R: CMSInstall only; ignore inbox flags
  C->>R: CMSQuery(name, item)
  Note over R: HasCMS → local estimate (may lag one RTT)
  C->>N: CMSQuery(name, item)
  alt N holds replica copy
    N-->>C: local estimate
  else non-replica
    N->>O: GetOrLoad(name)
    O-->>N: FlagCMS snapshot
    N-->>C: cmsx.Query
  end
```

**Hint-after-down (normative):** two `CMSIncr`s of **different** items while replica B’s Peer is down; then start B and wait for hint flush. The pending hint is the **latest snapshot** → B’s sketch contains **both** items. Copy HLL/TopK/List/JSON/Bitmap ring/transport/down setup (`TestHLLHintAfterPeerDownKeepsBothItems` / `TestTopKHintAfterPeerDownKeepsBothTracks` / `TestListHintAfterPeerDownKeepsBothPushes` / `TestJSONHintAfterPeerDownKeepsBothPaths` / `TestBitmapHintAfterPeerDownKeepsBothBits`). **Do** require both items (this is why we chose snapshot). **Do not** copy Hash’s “do not require both fields.”

Because items are hashed, the test asserts:

1. After flush, `engB.CMSQuery(name, a)` **equals** `engA.CMSQuery(name, a)` and the same for item `b` (identical snapshot ⇒ identical estimates).
2. Each item’s estimate is **≥ 1** so a lost first item (`Query(a)==0` on a live sketch that only saw `b`) fails.
3. Optional stronger check: `Peek` `Value` bytes equal on A and B (`DenseSize`).

A third `CMSIncr` “to poke the pool” is allowed only if the assert still requires **both original items**, not only the poke.

### Handoff is LWW, not merge (locked)

Cell-wise **sum** is the mathematically correct union of two CMS sketches of **disjoint** streams. Cell-wise **min** is a conservative merge that can only lower counts. **Handoff / replica apply / `GetOrLoad` install must not call either.**

Two concurrent writers on the **same name** serialize on the owner store mutex, so snapshots are **total-ordered**. Incoming `FlagCMS` with `version > local` **replaces** the blob (`CMSInstall`). Equal = ignore. Tombstone `<=` blocks. This is `HLLInstall` / `TopKInstall` / `BInstall` / `JInstall`, **not** Bloom `BloomMerge` (bitwise OR).

Do **not** sum-merge or min-merge incoming snapshots. A delayed lower-version sketch must not raise (or lower) cells that a later `Delete`+recreate (or a later owner generation) replaced. Version gate + replace is the contract.

`cmsx` does **not** export `Merge` in v1 (HLL exported `Merge` for package tests and then forbade calling it from install — skip the foot-gun).

## Approach

### Algorithm (locked — Count-Min, stdlib-only, not Redis-numeric-compat)

Package **`pkg/cmsx`** (matches `pkg/hllx` / `pkg/bitmapx` / `pkg/topkx`).

Cite: Cormode & Muthukrishnan, *[An Improved Data Stream Summary: The Count-Min Sketch and its Applications](https://www.cs.rutgers.edu/~muthu/cmss-day1.pdf)* (Journal of Algorithms, 2005; also LATIN 2004) — **normative**. Wikipedia [Count–min sketch](https://en.wikipedia.org/wiki/Count%E2%80%93min_sketch) is background. Do **not** lock RedisBloom `CMS.QUERY` numbers or MurmurHash2. Do **not** cite Space-Saving / HeavyKeeper as this algorithm.

**Parameters (locked — one blob size, like HLL `p=14`):**

| Knob | Value |
|------|--------|
| Depth `d` | 4 |
| Width `w` | 2048 |
| Cell | little-endian `uint64` |
| Encoding | dense only, **65536** bytes, **no header** |
| Hash | alloc-free **FNV-1a 64** + `mix64` (**same as `pkg/hllx`**, not `bloom.hash2`) + Kirsch–Mitzenmacher **indexing** |

Why lock dims, not `CMSWidth`/`CMSDepth`: HLL locked `p=14` because a hashed sketch has one natural SuperCache size and Validate/install stay trivial. Bloom/TopK knobs exist because *m* and *K* **are** the product (false-positive target; chart length). CMS error depends on the use case in theory, but v1’s dedicated story (billboard N=1220) is well inside `εN ≈ 1.6` at w=2048, and 64 KiB is `<< 1 MiB`. Shrink-under-live (same foot-gun as shrink-K) is avoided entirely. Width/depth knobs are a follow-up if a real keyspace needs a different ε.

`cespare/xxhash/v2` is only an **indirect** dep (`go.mod` via `github.com/redis/go-redis/v9`). Do **not** take it as a direct module. **Hash source matches HLL** (`pkg/hllx` alloc-free FNV-1a 64 + `mix64` split of one 64-bit word). **KM indexing matches Bloom** (`(h1 + i*h2) % m` with odd `h2` in `pkg/bloom/bloom.go` `Add`/`Test`). Do **not** copy `bloom.hash2` constructors (`fnv.New64a()` + `fnv.New64()` allocate).

Estimates **will not match** Redis `CMS.QUERY` on the same items. RedisBloom uses MurmurHash2 and per-key `CMS.INITBYDIM`. SuperCache has no Redis dump import. Tests lock **overestimate + error bound**, not Redis parity.

**Index (locked — Kirsch–Mitzenmacher, one 64-bit split):**

```text
x     = mix64(FNV-1a-64(item))          // same mix64 as pkg/hllx
h1    = x >> 32
h2    = (x & 0xffffffff) | 1            // odd: (h1 + i*h2) mod 2048 covers all columns
for i := 0 .. d-1:
    col_i = (h1 + uint64(i)*h2) % w     // impl may use & (w-1); w is 2^11
    cells[i*w + col_i] += n             // reject first if any cell > MaxUint64-n
Query(item) = min_i cells[i*w + col_i]
```

`mix64` is the splitmix64 finalizer already in `pkg/hllx/hllx.go` (FNV-1a high bits avalanche poorly). Paste it next to `Hash64`; do not import `hllx` from `cmsx`. The **index** formula `(h1 + i*h2) % w` with `h2` forced odd is Bloom’s KM step; the **64-bit input** is HLL’s `mix64(Hash64(item))`, not Bloom’s two independent FNV constructors.

**Overflow (locked):**

```text
delta = n; if delta == 0 { delta = 1 }       // 0 means 1
Incr(item, n):
  compute the d cells
  if any cell > MaxUint64-delta: return ErrOverflow   // no mutate
  add delta to all d cells
  return nil
```

All-or-nothing. A wrap would turn a cell into 0 and **underestimate**. Engine maps `ErrOverflow` to `ErrInvalidArgument`; store returns `applied=false`, `tooLarge=false`; previous bytes **and cost** unchanged. No `Add` helper — tests call `Incr(item, 1)` or `Incr(item, 0)` (same delta).

**Guarantees tests may cite:**

- `Query(item) ≥ true count(item)` always (overestimate only), for any item that was only incremented on this blob.
- With probability ≥ `1−δ` (`δ = e^{-d} ≈ 0.018`), `Query − true ≤ ε·‖a‖₁` (`ε = e/w ≈ 0.001327`).
- Same item twice via `Incr(..., 1)` (or `n=0`): `Query` increases by exactly 1 (not HLL-idempotent). `Incr(item, n)` with `n≥1` increases that item’s estimate by exactly **n**.
- `|blob| == 65536` always after `New`.

```go
package cmsx

const (
    Depth     = 4
    Width     = 2048
    CellBytes = 8
    DenseSize = Depth * Width * CellBytes // 65536
)

var (
    ErrSize     = errors.New("cmsx: bad sketch blob size")
    ErrEmpty    = errors.New("cmsx: empty item")
    ErrOverflow = errors.New("cmsx: counter overflow")
)

// New returns a zeroed dense sketch (DenseSize bytes).
func New() []byte

// Incr adds delta to the d hashed cells in place.
// n==0 means delta=1. ErrEmpty / ErrSize / ErrOverflow.
// Overflow leaves every cell unchanged.
func Incr(sketch []byte, item []byte, n uint64) error

// Query is min of d cells. All-zero / unseen / empty item → 0. Bad size → 0.
// Empty item does not panic. Engine CMSQuery still rejects empty before store.
func Query(sketch []byte, item []byte) uint64

func Hash64(item []byte) uint64 // alloc-free FNV-1a 64 (same as hllx)
func mix64(x uint64) uint64    // splitmix64; same body as pkg/hllx

// Inbox codec for FlagCMSIncr Value. Empty item → error.
// EncodeInbox writes the effective delta (n==0 → 1).
func EncodeInbox(n uint64, item []byte) ([]byte, error)
func DecodeInbox(b []byte) (n uint64, item []byte, err error)
```

Inline FNV-1a + `mix64` (stdlib constants; do not call `fnv.New64a()` on the add path; do not import `hllx`):

```go
const (
    offset64 = 14695981039346656037
    prime64  = 1099511628211
)

func Hash64(item []byte) uint64 {
    h := uint64(offset64)
    for _, c := range item {
        h ^= uint64(c)
        h *= prime64
    }
    return h
}

// mix64 is the splitmix64 finalizer copied from pkg/hllx/hllx.go.
func mix64(x uint64) uint64 {
    x ^= x >> 30
    x *= 0xbf58476d1ce4e5b9
    x ^= x >> 27
    x *= 0x94d049bb133111eb
    x ^= x >> 31
    return x
}
```

Goldens (pin the index, not only FNV):

```text
Hash64([]byte("a"))              == 0xaf63dc4c8601ec8c   // same as hllx.Hash64
mix64(Hash64([]byte("a")))       == 0x02c0bdbf481420f8
```

**Encoding (locked — dense `d*w` LE uint64, no header):**

```text
cell[row*Width + col] at byte offset (row*Width + col)*8, little-endian uint64
```

Dims are **not** in the blob (like HLL `p` and TopK `K`). Incoming `len != DenseSize` → reject. Empty / short / padded blobs are not sketches.

First add allocates the full dense blob (like HLL dense-only; no sparse).

### Store (`pkg/store`)

Last shipped bits in `pkg/store/entry.go`: `FlagTopK` `1<<27`, `FlagTopKAdd` `1<<28`. Next free is `1<<29`:

```go
FlagCMS    uint32 = 1 << 29 // value is dense 64 KiB Count-Min snapshot
FlagCMSIncr uint32 = 1 << 30 // owner-inbox only: uvarint(n) || item (replicas ignore)
```

`Entry.IsCMS()` / `IsCMSIncr()`. `1<<31` stays free. One inbox flag, n in the payload.

**No `cmsCache` / `cmsDirty`.** The live structure **is** `Entry.Value` (like HLL / Bitmap / Counter / Bloom / TopK, unlike JSON/List/Hash). Mutate cells **in place** under the store mutex. **Do not** add `flushCMSValueLocked` — a Get/Peek helper that is easy to get wrong on the KV hot path. Peek/Get already clone `Value`.

```go
// store.Store
CMSIncr(key string, item []byte, n uint64, version uint64, expireAt int64, maxValue int) (applied, tooLarge bool)
CMSQuery(key string, item []byte) (n uint64, ok bool)
HasCMS(key string) bool // live unexpired FlagCMS
CMSInstall(key string, blob []byte, version uint64, expireAt int64) bool // incoming > local
```

No store `CMSAdd`.

**`CMSIncr` (locked).** Gate first; **only a successful apply mutates**. Effective `delta = n; if delta == 0 { delta = 1 }`.

1. Empty item → `applied=false`; no write.
2. Live non-CMS → `applied=false`; no write.
3. Live unexpired tombstone and `version <=` tombstone → `applied=false`; no write.
4. `maxValue > 0 && DenseSize > maxValue` → `tooLarge=true`, `applied=false` (**before** allocate).
5. Missing / expired / tombstone with `version >` tombstone → **create**: `cmsx.New()` + `cmsx.Incr(..., n)` (`n==0` → +1). `Incr` error (empty item) → `applied=false`, `tooLarge=false`, no insert. Else `Version=1` (or `tombstone.Version+1` when replacing a tombstone), `Flags=FlagCMS`.
6. Live CMS: `len(Value) != DenseSize` → `applied=false`, `tooLarge=false`, **no mutate, no recreate, no pad**. `cmsx.Incr` **in place** on `it.entry.Value` (same backing array). **`ErrOverflow`** → `applied=false`, `tooLarge=false`, previous bytes **and cost** unchanged (Incr must not have mutated — check-then-increment).
7. Commit under this mutex: `Version = 1` on create (missing/expired) or `local.Version+1` when replacing live CMS / a superseded tombstone; `Flags=FlagCMS`; slide `ExpireAt` if `expireAt != 0`; cost; `MoveToFront`; `evictLocked`. Incoming `version` is **not** written (tombstone-gate floor only — step 3).
8. An incr that does not change a *different* item’s estimate **still** commits (version + TTL). There is no “unchanged → skip” path. The item’s own estimate always +delta on success.

In-place add may mutate `it.entry.Value` bytes under the mutex. Peek/handoff clone.

**`HasCMS` (locked):** copy `HasHLL` / `HasTopK` / `HasBitmap` **flag** gate — live, unexpired, not tombstone, `IsCMS`. Do **not** require `len(Value) > 0` and do **not** require `Query > 0`.

**`CMSQuery`:** `HasCMS` + `cmsx.Query`. Missing → `ok=false`, `n=0`.

**`CMSInstall`:** same gate as `HLLInstall` / `TopKInstall` / `BInstall` / `JInstall` (`incoming > local`; equal ignore; tombstone `<=` blocks). Reject `len(blob) != DenseSize`. Replace with a **copy** of `blob`. No decode beyond the size check.

**Stored version (locked):**

```text
stored = local.Version+1          // live FlagCMS, or replace tombstone after gate
stored = 1                        // CMSIncr create (missing / expired; no local entry)
incoming version                  // tombstone-gate floor only
```

Engine **must** replicate `PeekVersion` **after** `CMSIncr` returns applied, not the candidate it passed in. `observeVersion` that same post-write version.

Protect live `FlagCMS` in `lruVictim` (`pkg/store/memory.go` today lists Bloom/Set/ZSet/Geo/List/Hash/Counter/JSON/Bitmap/HLL/TopK).

`Set` / `AcceptIfNewer` need no CMS cache to clear.

### Engine (`pkg/engine/cms.go`)

Mirror `pkg/engine/hll.go` **inbox + snapshot**, not Hash item-apply and not Bloom replica-OR. Split apply/fetch helpers into extra files only if `cms.go` gets large (TopK’s `topk_apply.go` / `topk_cluster.go` is optional style, not required).


No `CMSAdd`. Engine does **not** reject `n == 0`; it forwards 0 and store/`cmsx` treat it as 1. Client helpers may pass `1` explicitly.

1. Validate `item`: empty → `ErrInvalidArgument`; `len(item) > e.maxKeyLen` → `ErrKeyTooLarge` (HLL/Bloom/List, **not** TopK `itemMax`).
2. Validate mode `ModeCMS`, `name` via `validateKey` + `validateKeyLen`.
3. `cmsNeed(ks)` — `DenseSize > max` → `ErrValueTooLarge` **before** any store/forward.
4. **Non-owner mutate:** `cmsMutViaOwner` = `ApplyPut` inbox (`EncodeInbox(n, item)`, so `n==0` encodes as `1`) `Version: 1`. If `err != nil` return it. If `!applied` → `ErrInvalidArgument`.
5. **Owner / single-node `CMSIncr`:** `expire := e.expireAt(ks.cfg.TTL)` + `max := e.maxValueSize` (ks override) + `store.CMSIncr(..., n, gate, ...)` where `gate` is `PeekVersion+1` (tombstone floor only). `tooLarge` → `ErrValueTooLarge`. `!applied` → `ErrInvalidArgument`. If applied → `ver, _ := PeekVersion(name)` then `ks.observeVersion(name, ver)` + `cmsReplicateSnapshot(..., ver, ...)`. **Never** fan-out the pre-lock candidate.
6. **`CMSQuery`:** validate item first. If `HasCMS` → `store.CMSQuery`. Else `cmsFetchOwner` + `cmsx.Query`. Missing → `0, false, nil`.
7. Get/Put reject `ModeCMS` (`use CMSQuery` / `use CMSIncr`) next to the ModeTopK branches in `pkg/engine/engine.go`.
8. `GetOrLoadLocal`: Peek + `IsCMS` (after TopK, same shape as HLL in `pkg/engine/cluster.go`). Missing → `ErrNotFound`.
9. `LocalEntries` already walks `RangeAll`; Value is always the dense blob.

```go
func (e *Engine) applyCMSIncr(ks *ksRuntime, name string, inbox []byte, expireAt int64) bool {
    n, item, err := cmsx.DecodeInbox(inbox) // uvarint(n) || item; Encode wrote delta≥1
    if err != nil || len(item) == 0 {
        return false
    }
    if expireAt == 0 {
        expireAt = e.expireAt(ks.cfg.TTL)
    }
    max := e.maxValueSize
    if ks.cfg.MaxValueSize > 0 {
        max = ks.cfg.MaxValueSize
    }
    cur, _ := ks.store.PeekVersion(name)
    gate := cur + 1 // tombstone floor only; store assigns the stored version
    ok, tooLarge := ks.store.CMSIncr(name, item, n, gate, expireAt, max)
    if !ok || tooLarge {
        return false
    }
    ver, _ := ks.store.PeekVersion(name)
    ks.observeVersion(name, ver)
    e.cmsReplicateSnapshot(ks, name, ver, expireAt)
    return true
}
```

`cmsFetchOwner`: copy `hllFetchOwner` with `IsCMS` + optional `CMSInstall`.

## Data model / migration

No on-disk format. No migration. New `Mode` iota and two `Entry` flags. Rolling: deploy the build cluster-wide, **then** `UpdateKeySpace` a `ModeCMS` keyspace. Old nodes would treat `Mode=13` as KV if a CMS keyspace were registered early — forbidden in the rollout.

## Security & Privacy Considerations

No new auth surface. Document names/items ride the existing Cache gRPC (TLS) and Peer ApplyPut (mTLS). Do not log item bodies or counter blobs (track ids are mild; the same API will be used for IPs / user ids / API keys). Limits (`e.maxKeyLen` on the hashed item; `validateKeyLen` on name; `DenseSize` vs `MaxValueSize`; `MaxBytes` may overshoot one live CMS) are the DoS bound — the blob is fixed-size, so the bomb is “many names”, not “one huge add”. Same tenant isolation: keyspace config is local and must match across nodes.

Owner **store mutex** serializes `CMSIncr` **and** assigns `stored = local.Version+1` (or `1` on create). There is **no** extra engine owner-mutate mutex — same as Hash/List/JSON/Bitmap/HLL/TopK. Two clients mutating the same name apply in store-lock order; successive snapshots have distinct versions so `CMSInstall` cannot drop the later one. A client that retries `CMSIncr` after a timeout may double-apply (a play counted twice). SuperCache does not have request ids.

CMS is **approximate and one-sided**. Do not use `CMSQuery` as an exact billing meter, royalty ledger, or sole rate-limit enforcer. Overestimates can deny a legitimate client if you treat the estimate as exact.

Threat notes:

- **Sketch as side channel:** the blob is a frequency table of hashed items; an attacker with a replica snapshot can query arbitrary items. Same class as HLL registers. mTLS on Peer is the control.
- **Many names:** each name is 64 KiB. `MaxBytes` is the budget; one sketch may overshoot.
- **Inbox item:** `FlagCMSIncr` carries `uvarint(n)||item` to the owner only; replicas see only the dense blob.

## Observability

Reuse existing fan-out / hint / `staleSkip` / store hit-miss counters. No new required metrics in v1. Optional later: CMS query histogram, overflow reject count, 64 KiB fan-out bytes. Wrong-mode, empty item, overflow, and oversize map through `grpcmap`.

Operational: every `CMSIncr` fans **64 KiB**. Billboard ingest of 1220 plays is ~78 MiB of CMS snapshots (plus TopK) — `runDemo` ingest deadline is **60s**, not the current 30s; a 30s flake is not a product bug. Demo `POST ?n=` is **one** CMS snapshot (`CMSIncr(n)`) plus n TopK snapshots. A station-day at 100k plays is ~6.4 GiB × (RF−1) replica traffic **if each play is its own `CMSIncr(1)`**; batching with `CMSIncr(n)` cuts that. Document both next to HLL’s 12 KiB tax.

## Rollout Plan

- Opt-in: nothing happens until an operator registers a `ModeCMS` keyspace on **every** node.
- Deploy the CMS build cluster-wide first; then `UpdateKeySpace`.
- Rollback: stop writing CMSIncr; `Delete(name)` or drop the keyspace. No on-disk format.
- No feature flag (mode is the flag).
- Billboard example is in-process only; it does **not** change stock `-demo-keyspace`.
- [`examples/billboard`](../../examples/billboard/) **is** the ModeCMS demo (frequency sibling `plays-count`). Official `charts` SoT and ModeTopK `plays` are unchanged in role.

## Alternatives Considered

| Idea | Why not |
|------|---------|
| `ModeCounter` per item | Exact, O(distinct) names; caller must create each name |
| `TopKQuery` / `TopKCount` on ModeTopK | “Not in table ≠ 0”; TopK design already refused to fake CMS |
| `ZINCRBY` on ModeZSet | Exact, unbounded, one LRU blob of **all** distinct; ZAdd already requires a score |
| Client-side map in a KV blob | Lost-update on Put; no owner serialize |
| Item-level `FlagCMSIncr` to replicas | Lost hints drop the other item; `hintID` is `(ks, name)` |
| Bloom-style hintID `(ks, name, item)` | Touches global hint path; Bloom is the documented exception |
| Hash-class item-level + “don’t require both items” | Accepts silent data loss; we can snapshot a fixed 64 KiB instead |
| Cell-wise sum-merge or min-merge on handoff | Not LWW-safe after Delete+recreate; HLL already refused max-merge |
| RedisBloom CMS v1 (Murmur, INITBYDIM, INCRBY, MERGE) | Extra surface; we refuse numeric parity anyway; MERGE is multi-key |
| Keyspace `CMSWidth` / `CMSDepth` | HLL locked `p=14`; shrink-under-live is a foot-gun; billboard does not need it |
| Conservative-Update / Count-Mean-Min | Extra algorithm; classic CMS is enough |
| Return the new estimate from `CMSIncr` | Would need a Peer RPC (`CounterIncr` class). CMS is approximate; callers `CMSQuery` after. ACK-only keeps one inbox flag |
| A separate `CMSAdd` verb | User: `CMSIncr` with default 1 is enough |
| `n == 0` as a touch / empty-create | Proto3 omitted `n` is 0; treat as **1**, not reject |
| Reject `n == 0` | Would make omitted proto `n` an error; CLI default would need a second RPC |
| Second inbox flag | Spends `1<<31`. One `FlagCMSIncr` + `uvarint(delta)\|\|item` is enough |
| Signed / decrement | CMS cannot go down without lying; Counter is the signed type |
| Retrofit `examples/ratelimit` | That demo is exact `Incr` returning *n* (Peer `CounterIncr`). CMS is ACK-only, overestimates, and is not an enforcer. High-cardinality “approx allow” is a different product. |
| New `examples/cms` mini-walkthrough | User wanted the real billboard for TopK; the eviction gap lives there |
| Replace ModeTopK `plays` with CMS | CMS cannot name the head; pairing is the lesson |
| Default CMS demo keyspace | Same as HLL/TopK; example starts its own mesh |
| `CMSIncr` pre-lock nextVersion as stored | Two version spaces; replica `CMSInstall` can drop the later snapshot |
| Peek/Get `flushCMS*` helper | Unnecessary (Value is encoded) and a Get-hit alloc risk |
| Names `ModeCountMin` / Redis `CMS.INCRBY` | Breaks Geo/Hash/HLL/TopK short-name convention |
| Export `cmsx.Merge` | HLL exported Merge then forbade install from calling it; skip the foot-gun |
| Invent a PLAN §1 fight | That line is “not RESP / not a Redis clone”; ModeCMS is a SuperCache mode |
| Change hintID in this PR | Touches global hint path; separate design |
| Client-built snapshot ApplyPut to owner | Two writers clobber; owner must apply the **op** |
| New Peer RPC / return estimate | CMSIncr is ACK-only; ApplyPut suffices |
